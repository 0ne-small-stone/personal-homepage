# 设计规范 v0.1

文档对应（2026-10-07 整理）：本文件是设计专项依据，组件主题、资源加载与降级由[技术规格](../technical/SPEC.md)和[技术验收](../technical/PLAN.md)承接。参数仍只在本文维护，文件与任务的映射见[文档对应表](../README.md)。

更新：2026-10-03。适用于本站自有界面。以下数值是第一版可直接使用的基线，后续通过小步验证调整；尚未实现为应用样式。现成阅读器、播放器和后台优先保留原生行为，通过其支持的主题能力适配。

## 1. 总原则

**迷幻、辽阔、温柔；功能清楚，动作有因。** 黑色首页与白色留痕墙属于同一空间。空间效果集中在首页与靠近过程；阅读时保持背景稳定。页面与功能归属见[页面规格](SPEC.md)，完整概念见[概念施工说明](CONCEPT.md)，迭代与验收见[工作流](PLAN.md)。

同一职责使用同一变量。实现时按“原始值 → 语义用途 → 组件”组织，例如 `--ink-900 → --color-text → --button-text`。组件读取语义变量；页面换深浅背景时替换语义映射，不逐个写新的颜色。

## 2. 颜色与明暗

| 语义变量 | 暗景 | 浅面 | 用途 |
| --- | --- | --- | --- |
| `--color-bg` | `#0B0D0F` | `#E8E4DC` | 页面底色；浅面也是白墙基色 |
| `--color-surface` | `#151A1D` | `#F2EFE8` | 需要稳定对比的内容/控件底面 |
| `--color-text` | `#F0EEE8` | `#272A2C` | 正文、标题、主控件 |
| `--color-muted` | `#B7BDBF` | `#62645D` | 辅助说明与元信息 |
| `--color-accent` | `#A8C7CC` | `#345B63` | 链接、当前项、焦点；使用时保留文字或边界区别 |
| `--color-border` | `#70787B` | `#72746E` | 必须辨认的控件边界，按不透明色使用 |
| `--color-success` | `#A9C3AE` | `#3F6547` | 真实成功状态，配合文字 |
| `--color-error` | `#EDB4AC` | `#9A3D35` | 错误与恢复提示，配合文字 |

- 细分隔线和装饰砖缝可以更弱；关键控件不能只依靠低透明度边线辨认。
- 光的色散只作局部冷暖变化，首轮使用上表 accent 与暖白，再验证是否需要额外色相。避免把每个栏目固定成一块高饱和彩色区域。
- 暗景/浅面是表面配色。首页与白墙按场景选择；阅读配色可独立调整，不改变场景进度。
- 普通文字目标至少 4.5:1，大号文字按定义至少 3:1；本站关键控件边界和焦点设计目标至少 3:1。[W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

**已做的数值检查：**2026-10-03 按 sRGB 相对亮度公式核算表内不透明前景色与两种同主题背景。文字及状态色最小对比度：暗景 9.22:1、浅面 4.73:1；边界最小值：暗景 3.89:1、浅面 3.73:1。此结果只验证色值组合；图片、透明度、辉光和蒙版参与后的实际画面需另测。边界色不用于普通文字。

## 3. 字体与排版

| 用途 | 初始规范 |
| --- | --- |
| 正文与控件 | 系统无衬线：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 展示性标题 | 优先试用思源宋体的明确授权版本，仅用于少量标题；未接入时用 `"Songti SC", SimSun, serif` 回退 |
| 代码与数字刻度 | `ui-monospace, Consolas, monospace`；时间与进度用等宽数字 |
| 正文 | 手机 16px、桌面 18px，行高 1.8，字重 400 |
| 控件标签 | 14–16px，行高 1.5，字重 500；手机表单输入文字至少 16px |
| 辅助信息 | 13–14px，行高 1.5；主要操作和错误说明不缩成小字 |
| 页面标题 | 手机 32px、桌面 48px；首页短标题可到 64px，行高 1.2–1.3 |
| 二/三级标题 | 24px / 20px，行高 1.4；清楚区分层级 |
| 正文宽度 | 约 36em，中文每行约 28–40 字；容器不得超过可用宽度 |

字号实现使用 rem 与响应式约束，尊重浏览器文字缩放。中文自然换行，长 URL/代码单独处理。字体文件优先本地托管、按实际字形和字重需要优化；核心内容在字体加载前即可读。项目未选定具体字体文件，采用时登记来源与许可，避免一次加载整套多字重中文字体。

## 4. 布局、边界与图标

- 间距阶梯：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px`；实现换算为 rem。组件内部优先 8–16，分组 24–32，页面章节 48–96。
- 页面侧距初值：手机 16、平板 24、桌面 40；内容容器最大 1200px，阅读正文使用独立窄栏。
- 宽度断点初值：768、1024px。根据内容重排，不能只把桌面场景等比例缩小。手机四入口按学习、展示、网站、电台顺序重排。
- 圆角：砖块/媒体 0–2px；按钮与输入 6px；展开面板 8px。胶囊只用于确有需要的标签或紧凑状态，不铺满页面。
- 普通分隔线 1px；焦点外框 2px、外偏移 3px。阴影只帮助区分展开层与背景，首轮不为每个卡片加阴影。
- 图标优先沿用已有组件；本站自有图标统一采用清单中的 Lucide 线性风格，常用 18/20/24px，描边统一。装饰图标不重复朗读，独立图标按钮必须有名称。
- 合成顺序：场景背景 → 内容 → 固定导航 → 弹层遮罩与弹层 → 状态提示。装饰层不接收指针事件；全屏弹层覆盖导航并管理焦点。

## 5. 控件与交互

本站独立按钮有效点击区以 **44×44 CSS px** 为设计目标，相邻独立目标优先保留 8px 间距；这是本站目标，高于 WCAG 2.2 AA 的 24×24 CSS px 基础要求（标准另有间距等例外）。正文链接保持可读的自然排版。[W3C 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)

| 状态/类型 | 统一规则 |
| --- | --- |
| 默认 | 目的地用链接，改变状态用按钮；文案说明动作与对象 |
| 主要动作 | `color-text` 作按钮底、`color-bg` 作字色；同一区域保持明确重点 |
| 次要动作 | 稳定底面、可辨边界与文字；工具链接可用文字和下划线 |
| 悬停 | 局部颜色/边界增强，点击区不变；必要说明同时支持焦点或点击 |
| 焦点 | 使用 accent 外框；不被裁切或遮挡；发光不能替代轮廓 |
| 按下 | 立即反馈明暗；不移动布局、不让小按钮追着鼠标走 |
| 选中 | 文字/图标/线条至少一种结构区别，并暴露对应状态语义 |
| 忙碌 | 保留宽度和任务名称，显示处理中；防重复提交，允许合理取消 |
| 不可用 | 语义与外观同时不可用，附近说明原因；不只降低透明度 |
| 成功/失败 | 在操作附近说明真实结果；失败保留输入并提供可行重试 |

输入框有持续可见的标签；占位文字仅示例。错误靠近字段，提交失败后聚焦错误摘要或首个错误。弹层有标题、关闭、Esc 和焦点恢复；有未提交内容时保留草稿或明确提醒。

切页后聚焦主要标题/内容；关闭恢复触发物；列表返回恢复条件与位置。外链明确平台与新窗口行为。滚轮控制只在主动激活的场景内发生，到达后释放。按钮编号与详细行为见[概念施工说明](CONCEPT.md)。

## 6. 动画与声音

| 动画变量 | 初始值 | 用途 |
| --- | --- | --- |
| `--motion-feedback` | 180ms | 悬停、边界、状态提示；输入后立即开始反馈 |
| `--motion-local` | 240ms | 菜单、局部展开、内容替换 |
| `--motion-page` | 360ms | 一般跨页接续、封面到详情 |
| `--motion-space` | 700ms | 按钮触发的完整空间接续；不用于规定滚轮总时长 |
| `--ease-enter` | `cubic-bezier(.22,1,.36,1)` | 柔和落定 |
| `--ease-exit` | `cubic-bezier(.4,0,1,1)` | 快速收起；初始退出时长约为对应进入的 75% |

滚轮/距离控件直接改变目标进度，几何与受光从同一 p 派生；平滑程度单独实测。按钮步进只改变目标距离，能被取消和新的输入打断。禁止依赖动画结束事件才更新业务结果；状态正确后再表现过渡。

同一时间保留一个主要运动焦点。阅读、输入表单时背景静止；离屏或页面不可见时暂停持续图形。普通控件不统一加入弹跳、磁吸或文字拆字。图片/砖块展开从其原位置发生，返回恢复原位置。

减少动画偏好下取消空间位移、视差、持续旋转，直接到目标状态；必要淡入不超过 100ms且可省略。监听并尊重系统偏好。[MDN：prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

声音默认关闭；用户明确开始播放或开启声景后才发声。歌曲、环境音、界面音分别有清楚的状态与关闭方式；歌曲播放时降低或关闭辅助声音。功能结果始终有视觉反馈，不能只靠声音告知。

## 7. 选图、材质与媒体

2026-10-07 T08.01 阅读器适配参数：PDF 原页面不改色；本站容器宽度 100%，高度 76svh、最小 28rem，媒体边界沿用 color-border、展开容器圆角 8px。PDF.js 工具栏高度 48px、上下内距 2px，主要图标按钮有效区 44px；阅读器自身宽度不超过 360px 时工具栏两行、高度 96px。隐藏新增批注工具，原件已有批注照常渲染；原生页码、缩放、搜索及更多菜单保留。全屏、下载和重试沿用本站独立目标规范；减少动画时取消侧栏过渡。此为执行者接入样本，用户审美验收待体验。

| 用途 | 选择标准 | 初始呈现 |
| --- | --- | --- |
| 个人照片/作品 | 真实、自有或用途明确；主体和故事清楚 | 保留原色与合理比例，不统一覆盖主题滤镜 |
| 项目封面 | 能说明项目，主体在手机裁切中仍可辨 | 列表优先 3:2；截图与正文媒体按内容比例显示 |
| 相册 | 统一观看节奏，记录说明与焦点 | 缩略图可裁切；放大查看完整图，支持竖幅 |
| 墙面 | 白色粉刷砖、自然细节、克制接缝、可平铺 | 同一材质测试黑暗、受光、白墙三状态 |
| 氛围素材 | 服务明确的空间或情绪需求，来源可追踪 | 少量使用，留出文字安全区，不冒充个人作品 |
| 音乐封面/视频 | 来源和展示方式明确 | 封面按原比例，播放或跳转与实际能力一致 |

先复用，再裁切/调色/压缩，最后才考虑二创或原创。每个采用素材记录来源、作者、许可、用途、原图、派生图、焦点、替代文本与修改。入口见[素材来源](REFERENCES.md)。

网页图片生成合适尺寸与格式，预留宽高，非首屏大图按需加载；原始文件保持完整。先评估每个用途的实际显示大小再设资源预算，墙面首轮从满足清晰度的较低分辨率试起，避免默认载入完整高分辨率材质包。装饰图替代文本为空，内容图描述可见信息。

## 8. 每次交付的快速检查

1. 字体、颜色、间距与动作来自统一变量；局部例外有记录。
2. 静止画面清楚；中间帧的文字、焦点和退出可见。
3. 当前任务能用鼠标、键盘及手机替代入口完成。
4. 加载、空内容、失败、未配置、真实成功分别表达。
5. 图片裁切、中文换行和减少动画经过本轮相关检查。
6. 记录使用的素材/组件及实际改造；未验证的内容明确标注。

调整本规范时同时检查受影响的公共组件与代表页面，并在迭代记录说明原因。完整验收范围按工作流选择，避免每改一个间距都重复全站检查。
