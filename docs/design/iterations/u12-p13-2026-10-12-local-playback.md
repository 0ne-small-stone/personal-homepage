# P13 洛雪下载音频的本机播放修复

日期：2026-10-12。对应 P13 / R04、R12 / U12 / T25.03，承接 T21.01、T21.03；用户反馈：“现在洛雪音乐的模式显示播放待连接”。

## 目标与诊断

原页面已读到18首真实歌曲、3张专辑，但公开索引的18个 `audioUrl` 均为空，播放器因此显示禁用的“播放待连接”。考拉此前两次官方授权后身份接口仍返回401/997，音乐文件夹、分享和上传未完成。没有把接口拒绝归因于用户未授权，也没有继续宣称云盘能播放。

本轮单一目标是让本机开发页播放已下载文件，沿用原生 audio 控件、当前构图及黑灰样式。现成 HTML audio 已覆盖播放/暂停/跳转；静态 Astro 不能直接访问本机下载文件，缺口仅为开发服务器按私有索引提供音频。沿用 Astro 官方开发钩子及 Node 文件流，没有新增播放器框架、依赖、常驻生产服务或账户认证。

## 实现与运行

- 索引生成被忽略的 `audio-map.json`，保存曲目 ID、相对文件名、大小/修改时间及私有下载目录。公开清单和镜像只含元数据。
- `astro:server:setup` 仅在 dev 挂载音频接口，按 ID 读取已索引文件；校验本机请求、Host/Origin、真实目录边界、允许格式和文件变化。支持 HEAD、完整 GET、单段/后缀 Range。
- 开发目录为已索引文件补同源地址，播放器显示“本机播放 · 考拉云盘待连接”；生产构建不补本机地址。文件改变尚未重新索引时返回不可用，页面提示确认文件并刷新。
- 私有映射与公开元数据分别计算更新签名，音频改动但标签不变时也能更新映射。模式切换暂停音频，返回后保持暂停。

先运行 `npm run music:index` 或保持 `npm run music:watch`，另一终端运行 `npm run dev -- --host 127.0.0.1 --port 4343`。当前索引监听及开发服务器已运行，入口：<http://127.0.0.1:4343/personal-homepage/music/?mode=cloud>。详细命令见[音乐接入工具](../../../tools/music/README.md)。
