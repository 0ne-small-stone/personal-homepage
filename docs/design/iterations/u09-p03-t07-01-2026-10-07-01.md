本轮唯一变量：学习总览的内容类型。概念依据：C03 的知识浏览及 C07 的可控阅读；参数沿用 [SYSTEM](../SYSTEM.md)。四个选项为“全部／资料／文章／笔记”，保留现有标题、演示说明、列表与阅读页面。

实现：[类型筛选组件](../../../src/components/KnowledgeTypeFilter.astro)、[学习总览](../../../src/pages/knowledge/index.astro)、[样式](../../../src/styles/knowledge.css)。类型来自同一批已发布知识；单选改变列表可见项、结果数量与 `type` 地址参数；选择“全部”清除该参数。浏览器前进后退及直接打开参数地址读取同一状态，不移动用户焦点。未知类型退回全部并说明；空结果可通过“全部”恢复。

复用与最小范围：保留 Starlight 阅读和统一列表；原生 radio 提供标签、分组、选中语义及键盘操作；Astro 自定义元素只补列表过滤和 URL 历史。已有 Tabs 是内容面板，不能直接覆盖本轮能力。来源、许可边界和[所需设计资源](../REFERENCES.md#t0701-学习类型筛选资源清单)统一在 REFERENCES 记录；本轮新增下载素材、框架及依赖为 0。未执行时不展示筛选控件，全部条目仍可读。

验证目标：全部 3 条，资料、文章、笔记各 1 条；刷新和直接地址保持类型，前进后退切换正确；键盘、手机、深浅主题及减少动画可用；未知参数、空结果与关闭 JavaScript 有真实降级。空结果通过浏览器临时样本验证，实际三条演示均保持原样。

实际预览：[学习类型筛选](http://127.0.0.1:4322/personal-homepage/knowledge/)。本轮在独立工作目录运行 Astro 原生后台生产预览；可在该目录执行 `npm run preview -- status` 查看，停止后用 `npm run preview -- --background --host 127.0.0.1 --port 4322` 恢复。

亲自验证：

1. 初始“全部”显示 3 条演示内容；依次选资料、文章、笔记，各显示对应的 1 条。
2. 选择“全部”恢复 3 条并清除 `type` 参数。
3. 复制 `?type=article` 地址或刷新后仍选文章；浏览器前进后退恢复之前的类型和结果。
4. Tab 进入分组，用方向键选择；焦点保留在控件，结果与数量立即变化。手机控件换行后仍可操作。

实际验证：Astro 检查 0 errors / 0 warnings / 0 hints；生产构建 14 页及 Pagefind，45 个产物文件、965,819 字节；既有原生 404 优先级提示沿用，无新增构建错误。Edge 临时浏览器 15 项检查通过，1440/768/390/320 宽及手机横屏无横向溢出，所有标签点击区达到现有规范目标。深浅主题、减少动画、原生方向键、焦点、地址参数、刷新、历史和详情链接均通过。脚本不可用时隐藏不可用控件，保留完整列表及可读提示。
