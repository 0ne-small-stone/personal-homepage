## 3. 七类效果之外的明确缺口

### A. 加载美术与揭幕：未完成独立设计落地

目前 `HomeJourney.tsx` 的 loader 是批准字标、准备文案、普通浏览按钮，场景首帧就绪后以 `.65s` 圆形 CSS 蒙版退出。具备功能加载与降级，不等于 34 轮美术方案完成。

ALCHE 的构图线生成、轮廓描绘、文字解扰、黑幕退场、带径向 UV 弯曲的场景显露尚未对应到本站。按已有“光中显影”方向改造，继续用本站字标，不复制 ALCHE 标识或为匹配时长伪造加载进度。

### B. 导航与控件微动效：只有部分样式

- `HomeHeader.astro:10` 存在 `data-scramble`，但全 `src` 未找到绑定实现；目前导航只有 CSS hover 下划线。
- `HomeCta.astro` + `home.css:25–29` 已有两行文字翻动、胶囊反色，不能把所有按钮都说成未做。
- 顶部 The Wall 当前只有反色；尚未做与整站一致的文字/图标状态样本。参考原站 SlotButton 与线条生长即可，不新增无证据的“标杆磁吸按钮”。

### C. 轮播背景的空间层次：参考站能力未覆盖

ALCHE 作品卡移动时，背后的图块、网格、光域仍共同构成空间。本站 `SceneBackdrop.tsx` 在 intro 结束即淡出；`home-motion.ts` 的后续 `model.progress=1` 让作品期背景基本全黑。本轮项目与网站卡画面也印证了这一点。

这是达到标杆整体感仍需解决的差距，不要求恢复用户已删除的背景白弧线、大字，或把纯黑黑灰主题改成彩色。后续应独立设计适合本站的低亮网格、局部媒体光与玻璃可读性，再做一片接入。

### D. 首页到栏目页的视觉交接：尚未形成完整转场

真实链接、章节/焦点保存及返回初始化已有实现。本轮点击 Afterimage 能进入真实项目页；浏览器后退恢复 `#projects`、scrollY=1540、焦点 `entry-projects`，loader 不重播。但尚未有标杆那样 GL 与 DOM 共同退场/入场、目标页标题承接的视觉链。

当前工作区 `HomeLayout.astro` 正有其他任务的 ClientRouter / 持久播放器改动，不能按源码存在路由器就宣布视觉转场完成，也不能继续将它描述为最终纯整页导航方案。后续沿用 Astro，不为复刻视觉更换 Swup。

### E. 首页环境音：未配置

`HomeJourney.tsx` 的环境音按钮为 disabled；本轮实际页面也显示声音未配置。环境音启用/静音、章节音景和选择反馈尚未接入。此结论仅指首页音景，不能推成音乐栏目没有播放器或没有开发。

### F. 留言闭环与真实内容：尚未完成

- `src/config/giscus.ts` 的 category / categoryId 为空，实际墙上显示“留言区暂未开放”。升墙动画完成不等于可留言。
- 一砖对应一段留言、点击展开留痕的表现未实现。它是本站早期主题愿景；当前明确接入基础是 Giscus，应先完成真实留言闭环，再独立决定如何将内容映射到砖，而不承诺 Giscus 原生支持这种表现。
- 首页项目/相册/音乐图仍是已获用户允许的专辑占位，项目落地页仍为“作品正在整理”。这不是动效失败，但还不是完整个人内容上线。音乐页已有独立开发，首页“待接入”说明须待集成核对，不能据此推断子页现状。

## 4. 不应误判成缺失

- 实心、统一半尺寸棱镜、没有 A 字缺口，是最新用户要求；不恢复原站大小/空心 A。
- 无首页左上 LSSH、无过场底部大字/说明句、无背景装饰白线，均为已要求删除。
- 字标、黑灰主题、知识区苹方、IBM Plex 字体栈与四入口是本站设计，不要求使用原站商业字体、六个作品或全部企业栏目。
- 原站有手机全屏菜单；本站 390px 三个固定导航全部可达、无横向溢出。尚无该菜单，但目前不作为必须新增的阻塞项。
- 暂停、减少动画、普通浏览及手机停用高成本流体属于合理适配，不应为了形式复刻删除。

## 5. 建议接续顺序与验收

保留首页开发正在做的光谱传输接入；本核查不打断该片，也不启动多个功能混改。

1. **完成当前光学接入并验收实际首页**：单 Canvas、旋转联动、静止收敛、白/彩界面、反向及减少动画；独立样例不可代验。
2. **末段全屏展开**：固定末卡退出基线，连续正向/反向与中断样本，真正从玻璃表面接管到墙，再接既有升墙。
3. **独立加载美术**：先静态构图，再一段揭幕，最后真实 readiness 与降级；字标不重画。
4. **补亮场流体与最终合成**：同一路径快/慢指针、停手消散、零场颜色不变、前景清晰；复用现有求解和渲染链。
5. **微交互与切页**：导航扰码→一个 CTA 状态样本→一条栏目往返转场，分别验收。
6. **补主题内容闭环**：真实留言、正式媒体、首页音景分别完成，不合并记账。

轮播背景空间层次另作一个可体验样本，避免同时修改已经验过的输入、几何和轨道。所有条目继续按“一片一个主要变量、实际输入证据、独立保存”推进。
