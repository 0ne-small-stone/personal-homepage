## 用户验收

1. 打开真实首页，点底部04，从常用网站卡继续慢慢向下滚动。
2. 看玻璃先接近方形，随后砖从上方落入、底部逐层砌起，同时窗口扩满屏幕。
3. 中间暂停或向上滚，确认节奏与形体自然；再向下到The Wall阅读态。
