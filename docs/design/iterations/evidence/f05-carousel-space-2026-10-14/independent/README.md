## 边界与保留项

- 读取DOM诊断与截图不是原子操作，运动中index/q/画面可相差一帧；短序列是离散原图，非完整录像、非逐帧流畅度证明。工具调度与屏幕缩放也不代表真实手指滚动。
- 轮播标题沿用既有交叠过渡，连接短序列可见两个标题暂时同场；本片没有改文字转场，不能以F05通过宣称F06/F07完成。
- 暂停/quiet沿用既有静态布局。预览seek/quiet模拟均在记录中分列；正常模式已经重新打开，受控hold不充当自然滚动证据。
- 真机、实际系统减少动画、GPU耗时、隐藏标签/BFCache专项、长时内存、网络失败/禁JS和线上部署未测。隐藏玻璃的开销没有独立GPU计时；帧循环字段transmissionVisible仅是材质标志，不能单独等同“当前确实执行透射采样”。
- 图片仍是已授权占位；音乐、相册、知识库、Someone、留言真实功能及新语言入口由各自负责人管理，本次仅使用实际Someone路径检验首页返回。
