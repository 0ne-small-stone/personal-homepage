## 操作

- 椭球：按可用画幅自适应；上下±35°、左右自由旋转，方向键提供替代，点击选中；向上滚轮或放大按钮连续进入空间。
- 空间：拖动或方向键平移，滚轮沿纵深穿行；W/S 前后、A/D 左右、Q/E 升降。原点附近向外退到阈值会收回总览，远处可用返回按钮或 Esc。
- Enter 进入；照片卡片可键盘聚焦，单图顶部缩略条提供照片切换；查看照片用原比例显示，前后切换和关闭不改变场景位置。右上球形网格按钮返回椭球总览。
- 单指拖拽、双指捏合的输入分支已实现；本轮仅实际验证鼠标、键盘和窄屏布局，真机触控另验。

## 实现与边界

原版170卡片的排布、曲面、透视、圆角、遮罩/模糊和惯性保持；第十片看图改为统一PhotoSwipe层。初始视野之外另188卡片作边缘覆盖，合计358。图片采用用户选择的contain/黑边，完整图不拉伸填框；图片/布局不再由第四片overview-layout.js驱动，该文件与旧验证脚本只保留历史。CSS矩阵转换世界姿态，Dome与Three共享相机/投影中心，空间候选≤640、共享36张纹理。正常三维朝向仍有透视压缩。

进入以镜头向前越过前排照片为主，照片墙的位置保持，内部XYZ影像场逐步显露。入口照片中心作为空间基点，其高度/17.5统一换算镜头/照片单位，镜头终点在入口之后；滚轮超过进入进度的余量接续空间飞行。空间使用官方确定性区域/种子、距离雾、透明度追随和滚轮速度积累，照片资源仍为36张样本，不代表无限真实内容。近镜头裁剪带来可见画幅截取，不改变图片自身比例。返回时共同重设空间基点/单位原点，保持返回起帧连续。

入口近图异步使用已有1600px派生，最多保留一张入口高清纹理；换入口和销毁时释放。选取复用Raycaster与圆角排除；移除顶点弯曲后，选取平面与可见几何一致。
