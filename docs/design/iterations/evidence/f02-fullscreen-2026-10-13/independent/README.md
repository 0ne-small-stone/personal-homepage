## 一批修正要求

### D1 · 展开主体分离（优先）

**实际现象：**`desktop-window-settled.jpg` 在桌面y=5896、expand=.275时，新墙面是独立斜四边形，原玻璃尖角仍从后方露出。随后玻璃本体没有成为正在铺开的边界，观感变成墙面贴片在玻璃前放大。这个阶段未满足施工卡B→C“从真实轮廓产生、外缘与厚度连续交接”的核心目标。

**修正目标：**窗口遮罩与玻璃边界使用同一套连续变形轮廓；原玻璃实体不能在新轮廓外留下第二个尖角。保留准备阶段的现有玻璃/柔光，在展开中让外缘、侧面和墙窗共同交接，避免白色无厚度贴片突然代替玻璃。只改F02转场内形体关系，首屏几何、半尺寸和56玻璃基线保持。

**源码线索（推断）：**`GlassTriangle`只轻微放大原实体并旋转，而`WallPortal`在屏幕空间将a/b/c/d独立插值成矩形；两套轮廓没有共同变形。请以可见连续性修正，不能仅把旧尖角藏掉后称为玻璃展开已完成。

### D2 · 砖缝沿三角形分割线扭折（优先）

**实际现象：**`desktop-window-settled.jpg`、`mobile-opening.jpg`及`mobile-retracted-settled.jpg`中，同一排砖缝在画面中部改变方向/拉伸，部分砖块形成阶梯、折线和异常收窄。不是正常透视下同一面平墙的连续直线，也不是设计要求的墙体折叠。

**修正目标：**小窗、半展开到屏幕采样的同一墙面保持连续、可追踪的砖缝；消除内部三角形拼接产生的可见导数折线。优先用现有Three场景投影/齐次透视映射，或统一四边形投影映射，继续复用一份墙场景和目标；不要用模糊掩盖，也不要增添贴图或另一个场景。最终屏幕采样、墙升起与反向门禁保持。

**源码线索（推断）：**`WallPortal`分别对两三角形作仿射重心UV，再与`vUv`混合，能位置连续但不保证对角线两侧的透视/斜率连续。需处理真正的投影关系和起点退化，而不是再改三角形排列。

### D3 · 展开轮廓锯齿

**实际现象：**桌面和390px截图的斜边、顶边、底边有明显像素阶梯；在`desktop-nav-boundary.jpg`中尤其可见，与项目圆润克制的玻璃轮廓不一致。

**修正目标：**对实际展开轮廓做按像素覆盖的抗锯齿，保留继承自玻璃的柔和边界；可沿用现有MSAA能力或shader导数/距离覆盖，避免硬`discard`直接切边。不要靠整面模糊、厚白描边或额外全屏Bloom遮盖。四角门禁仍按真实轮廓计算。
