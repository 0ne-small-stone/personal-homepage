## 画面判断

1. 三角阶段仍为暗色玻璃；近方阶段仍为空窗，没有先铺一张墙再开始落砖。
2. 起始只露出少量不同高度的砖，底部先累积。中段墙顶形成缓缓起伏的前沿，上方保留黑色空间，没有恢复整排同步下落。
3. 砖面的灰白层次和缝隙比较轻，落下砖与已砌成区能够区分；观察中未见浓重沟槽、尘土、弹跳或额外装饰。外观保持抽象、克制。
4. 窗口扩大与砌墙同时推进；完成后同一墙面停住并出现阅读内容，四角没有露黑或第二面墙接缝。
5. 桌面 The Wall 按钮在明暗交界处仍保持完整胶囊和统一文字颜色，最终再整体交接。窄屏现有顶栏/底栏可读；最终标题、正文与链接可辨认。这里只作实际读图判断，没有把它写成逐像素 WCAG 对比度测量。

艺术性是否达到用户期待仍由用户体验决定；本次判断允许保留这一候选，不追加自行美术循环。
