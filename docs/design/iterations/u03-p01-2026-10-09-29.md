# P01 · 玻璃旋转的输入响应

日期：2026-10-09。P01 / R01、R12 / U03、U05 / T03.01。基线颜色修复16257f8、归档923a8e4；第28轮设计侧允许保留颜色路径，最终宽面高光未通过。

## 任务与单轮边界

按现行SYSTEM9.2.3及HOMEPAGE_ALCHE_HANDOFF第0节，将旧章节固定姿态/正弦缓转替换为指针追随残差、中心权重、worksRotate阶段、真实Lenis滚速及回正。玻璃应表现为可拨动且有连续惯性的空间对象；静置顶部保持中性，进入作品自然转动，停手保留回正过程。

复用现有Three四元数、MotionLerper、Lenis和唯一R3F时钟，少量适配原站输入链与本站生命周期；现成UI动效组件无法覆盖该三维状态链，无新依赖。保留材质、几何、尺度、卡片、CameraRig和返回初始化控制器。

1. 读取精确源证据和实际输入/生命周期，记录一个主变量。
2. 实现旋转链；首次指针、离窗、暂停/继续、隐藏/显示、27初始化revision和手机hover能力分别处理。
3. 同一批采顶部静置、指针区域、阶段反向、正反滚速、生命周期五段连续读回与少量关键帧；与原站做受控约60Hz输入对照，实际时间/设备限制另记。
4. 失败集中修正，最多一轮确认；check/build、最小本地提交和证据归档。设计复核与用户确认另记。

## 实际实现

实现提交 `10075bd6537a08196103a877b95c0f4925d42c17`。新增 [glass-rotation.ts](../../../src/components/home/glass-rotation.ts)，只适配既有旋转控制。最后NDC进入倍率1的L，读更新前current/residual；真实Lenis速度夹幅进入倍率.5的L。阶段读取真实phase，worksRotate用封顶GL delta累计和精确sigmoid，intro→works相同目标不重启；四元数按鼠标→基础/滚速的前乘顺序再回正。

冷启动、实际返回消费27初始化revision，清空旧输入与临时Euler、置中性四元数和阶段目标。暂停/隐藏保留姿态及阶段进度，继续对齐最新指针、清旧残差；暂停后的layout revision不当作新访问重置。首次有效输入及重新进入窗口直接对齐L；离窗保留最后NDC、停止hover驱动，避免强制归零拨动。hover由实际fine/hover媒体能力决定，窄桌面仍可拨动，无hover手机仍有基础/滚动旋转。

Geometry、尺度、材质、环境、卡片、CameraRig、package/lockfile与基线无diff；新增的是输入生命周期和只读诊断。相机继续读取独立的绝对指针位置；离窗保留NDC后，相机可保持偏移，与玻璃的回正分开。唯一RAF仍由R3F驱动Lenis；没有额外动画循环。
