## 单轮目标与边界

让身份文案和实际可操作状态同步：实际滚动 0–100px 内共同退出，阈值处隐藏并释放焦点，反向恢复；首卡 CTA 在自身延迟阶段不可命中或聚焦，开始显示后才开放。

保留原有双追随、卡片曲率、中央锚点、The Wall 图像比例、逐字动画、栏目返回和静态内容。本轮不改玻璃、相机、四卡素材、SYSTEM 或其他工作区的 Becoming 功能。

动作依据：身份先让出背景标题的空间；控件只在其对应内容可见时开放。复用现有 Lenis、ScrollTrigger、GSAP 和原生 inert，不增加依赖、素材或时钟。

## 最小验收

1. 桌面 1440×900：实际 S=0/50/100/325/550；手机模拟 390×844：0/100/中段。保存 opacity、visibility、inert、aria-hidden、焦点和截图。
2. 实际点按一次 S=50 的探索入口；焦点在身份层越过 100px 时移到 LSSH，其他焦点保持，scrollY 不跳变。
3. 一次真实滚轮正向后快速反向，按浏览器实际收到的时间记录，确认身份恢复。
4. 首卡进入 0–300ms 每个浏览器 RAF 记录 CTA 自身与祖先有效透明度、inert、命中和焦点；检查隐藏时的真实聚焦尝试、反向取消和再次进入。
5. 首卡停驻及 CTA → 项目栏目 → 浏览器返回，先显示再恢复焦点；暂停、图形失败、减少动画和无 JS 保留正常内容。
6. 只执行本片的类型检查、生产构建和必要仓库检查；不重采原站或扩大完整动效验收。

## 实现

仅改 `src/components/home/home-motion.ts`：身份层读取真实 S，以 `1-q²(3-2q)` 在 0–100px 退出；100px 同时设置 visibility/inert/aria-hidden，反向直接恢复。焦点在身份层内才移至 `.home-brand`，使用 preventScroll。

项目 CTA 自身设置 inert/aria-hidden。进入时保留原有 .3s 延迟，在说明 tween 的 onUpdate 中检查 CTA 与父容器实际 opacity 及当前项后开放；离开立即关闭，kill 原 timeline 同时取消旧回调。返回分支先设置容器、文字、说明到完整可见，再开放 CTA 并由原返回机制聚焦。清理时同时移除新加的身份 visibility/aria-hidden 与 CTA 门禁。

复验脚本为 `tools/qa/p01-visibility.cjs`；before/after/confirm 的含义及运行环境见 [QA 说明](../../../tools/qa/README.md)。仅供人工验收辅助，不安装测试依赖、不加入产品界面或 CI。

## 实际结果

### 身份层

| 实际滚动 S | 修复前 opacity / inert | 修复后 opacity / visibility / inert / aria-hidden |
| --- | --- | --- |
| 0 | 1 / false | 1 / visible / false / 无 |
| 50 | 1 / false | .5 / visible / false / 无 |
| 100 | 1 / false | 0 / hidden / true / true |
| 325 | .75 / true | 0 / hidden / true / true |
| 550 | .5 / true | 0 / hidden / true / true |

手机模拟 390×844 的实际 0/100/550px 同样通过；桌面 550px 与手机 550px 已实际查看，字标不再与 Afterimage 重叠。桌面 50px 探索入口实际点击进入项目章；实际 Tab 在 50px 到达探索入口、100px 跳过它。

探索入口聚焦后从 50→100px，焦点移至顶栏 LSSH，实际 S 保持 100px；原焦点位于 Becoming 时保留该焦点。真实 CDP wheel 的 +300 / -300 都为 trusted，实际收到间隔约 **295.8ms**，不把请求等待 220ms 当作接收间隔；轨迹越过隐藏阈值再回到顶部，身份恢复 opacity=1、inert=false。

### CTA 与返回

- 首次进入采 **21 个浏览器 RAF/状态点**；其中 **11 个自身 opacity=0 的状态点全部 inert、hit=false，真实 focus() 尝试未聚焦**。记录包含自身、祖先乘积、有效透明度、当前焦点及命中对象。
- 首次采到开放的实际 elapsed 为 **300.5ms**，自身 opacity=.1097，父容器=1；这是采样中首个开放点，不当作动画精确启动时刻。
- 最后确认在实际激活后 **151.9ms**、CTA 仍为 0/inert 时回到 1400px，之后 800ms 的读取没有旧回调重开；重新进入仍先关闭、再显示开放。另用真实 Tab 验证跳过延迟 CTA。
- 1900px 首卡停驻保持 The Wall 完整比例和真实邻图，截图已查看。实际点击项目入口进入 `/personal-homepage/showcase/`，浏览器返回后为 **1900px / entry-projects**，CTA 自身及祖先 opacity=1、inert=false，loader=0。返回截图采在恢复后的首帧，DOM 已完整显示，GL 卡片仍在追赶；不将该帧称为场景已停稳。
- 暂停动态、主动丢失 WebGL 上下文均清理身份与 CTA 新状态；减少动画保留正常内容，无 JS 的探索入口可见。无非预期 pageerror，桌面与手机采样无横向溢出。
