# P01 · ALCHE 三角体尺寸与比例校准

2026-10-10。P01 / R01、R12 / U03、U05、U14 / T03.01、T03.05。用户最新要求：“三角体具体的大小和比例请复刻alche”。

## 1. 单片目标

按 ALCHE 的实体尺寸、内孔比例、前后深度和同视口投影校准本站三角体。此前逐次试调的横向拉宽、半尺寸、15%放大、内孔 .65 退出当前尺寸目标。39轮连续光晕、现有居中锚点、背景、字标和输入逻辑沿用。

## 2. 依据与边界

- 原站：https://alche.studio/ 。已实际打开；研究数据来自其公开 `common/scene.glb` 的 `Alche_A.geometry`，源文件只存临时目录，不作为本站发布资产。
- [原始测量 JSON](evidence/u03-p01-2026-10-10-40-design/measurements.json)：包围盒、前平面边界环、尺寸、比例、模型哈希和同相机投影计算。
- 原站调用链见[17轮源码研究](u03-p01-2026-10-08-17.md)：取 geometry 后局部乘3、父乘4.3；不沿用GLTF节点自带位移。相机 fov 随宽高比变化，首屏有一秒 zoom。
- 本站继续以视口中心为锚点；原站 A 字的底部字形缺口不属于本站三角环概念。复建我们的规则三角环，匹配外包络、孔洞和深度，原站模型/字形不直接接入。
- 屏幕占比用实体投影界定，发光模糊不算几何边界。原站亮面受背景和指针视差影响，不能用最亮像素或某张旋转截图判断体积。

尺寸统一参数见 **SYSTEM 9.3.7**；此单不重复维护数值。

## 3. 开发提示词

1. 检查 `GlassTriangle`、`CameraRig`、`GlassEdgeLight`、`GlassGlow` 与共享 `sceneUnitScale`，以已测单位转换重建几何。按真实含倒角包围盒收敛尺寸；不能只把旧 .6555 换成新常数而保留旧宽高比和内孔。
2. 继续用现有 Three Shape / ExtrudeGeometry，按测量独立匹配前表面孔洞与实体总深度。围绕几何包围盒中心旋转；固定尺度适用于桌面/手机，视角自适应由同源相机承担，删除旧手机额外缩小系数。
3. 光层继续从实际 Shape/geometry 提取内外轮廓，沿用39的独立mask和合成。可更新必要的几何绑定，不另调颜色、强度、模糊美术；不得重新生成前后两片光。
4. 检查尺寸变大后与当前终章几何映射的耦合，只修本片引入的回归，不趁机重做全屏展开。背景、导航、首页字标、文字安全区均保持。

## 4. 一批可验证交付

- 桌面1440×900、手机390×844，DPR1，首屏/相机zoom稳定/同姿态；记录实体包围盒、内孔、总深度、相机、实际投影宽高、bundle。
- 尺寸三轴对测量目标误差≤1%；外形宽高比和孔洞宽高比误差≤1%；同相机正面投影宽高误差≤2%。区分源站原始模型（含A底部缺口）与本站规则环的细部差异。
- 正面、60°侧视（桌面），正面、85°侧视（手机）各一次；原站桌面/手机截图与本站同视口并列留证。原站自然手势角度不强行宣称为固定60°；固定角度仅用于本站几何与光晕检查。
- 一次原生滚动到首卡并反向、一处links→wall当前接管核对，关注尺寸/遮挡/收光回归。一次check/build，真实控制台/Canvas/手机溢出检查。
- 初批集中检查；有具体缺陷时修一次后定点确认。通过后直接最小提交、工程短报告，不重复等待开工批准。用户审美确认另记。
