# 首页逐功能开发与用户验收

2026-10-13，用户要求：“你以功能为单位一步步开始开发并让我验收”。依据 [差距核查](u03-p01-2026-10-13-alche-gap-audit.md)，仅管理 P01/P14 首页队列；既有 U/T 编号与工程轮次不改名。

## 交付规则

1. 同时只交付一个可独立体验的功能；功能内部可拆工程步骤，全部收束后才请求用户验收。
2. 首页开发负责实现、工程核对和稳定的本机体验入口；设计对话负责范围、参考、实际读图与交互复核。
3. 一次集中检查桌面与窄屏，必要时集中修正，再做定向确认。构建/测试不能替代可见画面。
4. 每次交付：功能名称、可体验入口、3–5 条操作、实际验证结果、已知限制、关键截图。状态区分“实施中 / 待用户验收 / 用户通过 / 用户要求修改”。
5. **用户通过当前功能后才开始下一功能。**反馈问题继续修本功能；不额外征求常规修复许可，不把没有回复当通过。
6. 开发过程中可整理下一项已有资料，但不并行改变下一功能的应用代码。

## F01 当前验收卡：中央玻璃三棱体与柔光

### 单一目标

按用户最新反馈恢复中央三角体的玻璃质感和柔光。使用透射材质和附着边缘Gaussian柔晕；不恢复入射束、彩色分光/光谱传输、体积散射或GPU流体。保留几何、姿态交互及首页章节旅程。此范围覆盖55平涂外观，见[56轮](u03-p01-2026-10-13-56-glass-glow.md)。

### 保留

中央锚点、实心圆角棱镜几何、统一半尺寸、原旋转/滚动姿态输入、透射玻璃与边缘柔晕、黑灰背景、字标、导航与章节内容。取消固定入射光、彩色分光、屏幕色差、流体和全屏Bloom；不修改全屏展开或栏目美术。

### 用户应能体验的五步

1. 打开首页：首屏中央三棱体能透见砖格背景，玻璃侧面有明暗和柔和边缘光；无独立入射束、彩色分光或流体畸变。
2. 移动指针并滚动：三角体仍沿既有输入改变姿态，背景不产生流体扭曲。
3. 点击“暂停动态”并继续：姿态和柔光保持静止/恢复正常；不存在光谱质量切换控件，其他有效控件仍工作。
4. 滚动至 Afterimage、音乐章节和 The Wall 再返回：作品前景层级、章节、导航、文字与真实栏目链接保持完整可读。
5. 桌面和390px窄屏检查同一首屏和中段：三角体保持居中/原尺寸比例，无横向溢出、遮挡或旧光学层。

### 交付门槛

- 首页只有一个 Three Canvas / Renderer；共享几何与真实渲染一致，不以第二个独立 demo 覆盖首页。
- `HomeJourney` 使用透射材质与独立局部柔光合成；不挂载 `SpectralTransport`、`PrismBeam`、`GlassOptics`、`BlackFlowLayer`，构建产物不含这些首页模块。
- 中央几何、锚点、scale、旋转与章节显隐规则保持；Triangle 使用 `MeshTransmissionMaterial`，`transmission=1`、`ior=1.45`、`roughness=.08`，单Renderer scene/backdrop可透见。
- 移除“光影细节”控件和失效加载文案；暂停、减少动画、普通浏览/错误降级仍可用。
- 首页开发做构建与类型检查，并实际检查桌面/窄屏及作品前景 layer 0/1 顺序；不得仅凭构建通过判定 UI 完成。
- 交付实际首页 URL 与最终构建标识，先设计复核，再标记“待用户验收”。56轮桌面/模拟窄屏实际检查及构建信息见[56轮记录](u03-p01-2026-10-13-56-glass-glow.md)；BFCache、context loss、实体手机GPU性能仍未在本轮回归。
