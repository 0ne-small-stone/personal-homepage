# U13 · P17 · T13.08 上传格式与恢复

2026-10-09 第 1 轮。P17 / R13 / U13 / T13.08。唯一主要变量是图片格式错误反馈与换文件恢复。执行者验证通过，用户体验待反馈。

## 依据与复用

沿用 P17 的 Pages CMS 托管后台、原生 Upload/Select/Close、Editor/Source 和 T13.02 自制功能样本；ui-ux-pro-max 的 error-feedback、submit-feedback、error-recovery 用于检查错误能否定位、输入保留及可重试。没有新主题、控件、图形、字体、动效或依赖，新增设计资源 0。原生正文说明增加五种允许格式、换图重试和勿刷新未保存正文，取消与公开上传边界保留。

## 实例结果

TXT 实际提示 `Invalid file type. Allowed: .jpg,.jpeg,.png,.avif,.webp`；弹窗保持、Select 不可用，标题/编辑器 HTML 保留。直接换已有 PNG 后新增缩略图自动选中、Select 可用；没有插入或 Save，关闭后原图仍只有一张、未保存文字还在。最后重载原文，Save disabled。固定稿及集合新建表单的格式与恢复说明已实显。
