# U13 · P17 · T13.05 未保存说明

2026-10-09 第 1 轮。P17 / R13 / U13 / T13.05。唯一主要变量是标题旁的未保存保留/放弃说明。原生取消结果与提示接入已验，二次离开确认未通过，用户体验待反馈。

## 依据与资源

沿用设计 SPEC 的 P17 后台边界，ui-ux-pro-max 用于核查原生可见提示、取消路径与实际结果。原本预期原生未保存确认，实测缺失后调整为两处 title 的原生 description，文案：“需要保留修改时先点击 Save，再离开。返回列表会放弃未保存内容。”没有新颜色、字体、图标、图片、动效或界面主题，设计资源新增 0。

## 实际结果与限制

新建、已有文章、固定验证稿三个入口的标题旁均实际显示说明。新建标题的 `aria-describedby` 指向该原生说明节点，未完成屏幕阅读器整体验证。原生英文 Save/Editor/Source 保留。

编辑标题和正文后点侧栏“文章”，未出现确认，直接丢弃未保存修改；再次打开为原文。新建填写后不 Save，点面包屑回列表；仍为四篇，再次新建为空。CUA reload 回到已存标题，没有观察到提示；普通浏览器关闭/键盘刷新手势不据此记为通过。托管菜单本次只观察到 View on GitHub，放弃使用“文章”返回。

此文案使保留与放弃结果明确，不能替代“留在编辑／继续离开”的二次确认；防止误离开仍是缺口。远程未误写通过，[技术记录](../../technical/iterations/t13-05-2026-10-09.md)给出实际前后 head/blob 与 src 树。
