# U10 / P10 球面照片墙到无限影像空间

日期：2026-10-13。关联 P10 / R06、R12 / U10、U14 / T12、T26、T27。

用户要求：“本身是一个球面照片墙，鼠标拖动能旋转、选中，鼠标滚轮能放大进入无限影像空间。”本片唯一主要变量是两种布局之间有同源锚点、可逆的连续过渡。

## 范围与复用判断

- 球面借鉴 React Bits Dome Gallery；空间探索借鉴 Edoardo Lunardi Infinite Canvas，来源/许可在 REFERENCES 登记。
- 直接堆叠两个组件无法保持同一照片、相机和反向进度。最小适配是在已有 Three.js 中复用投影、纹理、射线选取，以一组图像对象连接球面和空间布局；仅原型使用，不改首页、音乐或主站依赖。
- 样本取当前 `图片/` 36 个本机 JPEG。仅压缩派生，不修改原文件；生成图片、包和清单在 `.local-tools/sphere-canvas/`，不公开发布。
- 参数唯一来源为 SYSTEM 第 10 节，原型源在 `evidence/u10-p10-2026-10-13-sphere-canvas/prototype/`。

## 验收目标

1. 球面拖拽旋转；点击与拖动有位移阈值，拖动/取消不误选照片。
2. 点击产生明确的选中状态；无选择时滚轮自动使用当前前方照片。
3. 向上滚轮/放大按钮连续展开到空间，途中反向可以撤回；不以黑帧、整页淡入或两个独立页面切换代替。
4. 空间内拖拽平移、滚轮缩放；区域循环生成并保持重访位置确定性。
5. 返回球面恢复此前朝向与选中；单图原比例查看、关闭后保留位置。
6. 键盘、触摸和减少动画可用；窗口变化、切后台/恢复无重复循环。
