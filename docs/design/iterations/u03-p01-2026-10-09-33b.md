# P01 · 33B边缘光施工提示词

2026-10-09。P01 / R12 / U03、U05、U14 / T03.05。前置：32身份已验收；33A形体对照收口后方可修改。本文件定义下一片，当前不是实现完成。

## 目标与现状

访客在纯黑抽象空间中能辨认玻璃的外缘、内孔与厚度，柔光从画幅边缘进入；保留当前砖格和曲线语汇。现有玻璃仍过暗，390×844背景只覆盖中间横带，见[手机实景](evidence/u03-p01-2026-10-09-32-design/mobile-intro.jpg)。本片主变量为背景光域及对应环境反射，覆盖适配属于它的必要条件。

## 保留与复用

沿用33A通过后的三角形、32完整站名、已有黑灰配色、原手写字标、SceneBackdrop程序化砖格和曲线。复用GlassReflectionEnvironment/softboxTexture、现有单Canvas与背景流体；参考依据为[33轮](u03-p01-2026-10-09-33.md)的ALCHE图层研究。所有候选数值只见[SYSTEM9.3.1](../SYSTEM.md#931-抽象边缘光与宽三角体)，不在本文件维护另一套数值。

## 本轮修改

1. **背景覆盖。**按可见画幅适配当前背景，横竖屏中都没有矩形贴片边界；保留砖块宽高比、错缝和单条曲线走势。不要通过修改CameraRig或把整张横图拉成竖图来遮盖问题。
2. **边缘光域。**主光从右侧中下边缘进入，左上弱回光，中心留黑；在原纹理或轻量shader中生成，不用写真、HDRI或AI背景。背景光可被原流体扰动、被玻璃折射，控件保持清楚。现有曲线可以随光域衰减，但不删除整套背景重做。
3. **玻璃对应反射。**改玻璃专用环境的亮区分布，形成一侧柔亮边和另一侧暗部，维持透明内孔。保持原透射、颜色转换、反射底数/上限、几何与相机；共享SceneLighting不是玻璃专用环境的替代。若仍未达到目标，记录实际通道原因，不加Bloom或霓虹描边遮盖。
4. **与滚动共存。**光域和背景同进同退；四张前景卡及DOM不进模糊。指针扫过、停手消散、反向返回沿用已有机制，不加自动循环新运动。The Wall仍由独立wall进度控制，本片不把终章提前。

## 一批验证及一次缺陷确认

- 同33A最终构建对照：桌面与390px的中性首屏、intro中点；同一相机、姿态、输入和进度，保存原图/实际主包标识。额外保留一张固定斜视，证明软边不是平面贴纸。
- 直接观察外缘、内孔、暗面；保留大面积黑、明暗不覆盖站名与导航。竖屏无背景硬切、无拉长砖；手机模拟不能宣称真机质量。
- 一段实际指针扫过/停手消散与短程滚动反向；一次首卡经过，确认前景卡/DOM清晰。原流体求解不改时不重跑全部旧数值研究。
- 低质量和暂停/减少动画继续可读；真实项目返回后光域位置、纹理和Canvas数正常；资源不每帧创建。检查GL错误、类型与生产构建，记录实际结果。
- 原图、连续输入证据、已知限制、可体验入口和最小提交。批量观察后只做一次针对实际缺陷的确认，设计侧再决定保留/退回。
