## 2. 唯一修改目标

**让首段文案顺序清楚，可见状态和可操作状态始终对应。**序章身份先退出，背景标题再取得视觉主导；项目 CTA 的延迟阶段保持禁用，实际显示后再恢复。

复用已有 Lenis / ScrollTrigger 的实际滚动位置与身份容器，不增加新的动画库或全局 timeline。参数统一写入 [SYSTEM 9.2.2](../SYSTEM.md#922-卡片背景与文字)。原站没有本站这组手写字标，因此退出映射明确属于 LSSH 适配。

保留卡片轨道、玻璃几何/材质、标题字形、品牌图稿及两张素材。只修首段文案的显隐与交互门禁。首卡之后未完的标题与媒体不纳入本片通过范围。

## 3. 发给首页开发的具体任务

1. 将 `home-motion.ts` 中身份层沿整个 works_intro 线性淡出的旧逻辑，改为 SYSTEM 规定的短退出区间。字标、短句与提示共同变化；不要只藏提示而留下大字标。
2. 到隐藏阈值时同步 visibility、inert、aria-hidden；向上回来恢复。身份层还在时，其探索入口仍有真实命中及键盘路径；已隐藏时不能留下透明命中区。
3. 如果用户将焦点放在探索入口后滚动越界，按规范将焦点移到顶栏身份链接且不改变 scrollY。离页或图形失败时清理状态；静态降级仍能阅读身份与探索入口。
4. 最小检查：1440×900 的 S=0 / 50 / 100 / 325 / 550，390×844 的 0 / 100 / 中段；一条正向后立即反向的连续记录，验证字标恢复。记录实际 scrollY、opacity、visibility、inert、aria-hidden、当前焦点。
5. 另外修正项目 CTA 自身的进入门禁：延迟阶段不可点/不可 Tab，实际开始显示才恢复；快速离开或反向取消旧回调，返回恢复先显示再聚焦。保留已有逐字时序，仅补状态约束。
6. 实际点按一次半退场的探索入口；键盘焦点越界一次；补首卡进入 0–300ms 的 CTA 自身和有效祖先 opacity / inert / hit-test 记录，再留一个首卡停驻与 CTA→返回抽查。沿用既有证据，不重复采完整原站素材。只针对本片执行 check/build 与必要检测。

通过条件：中段不再发生两组大字相压；身份层可见时没有提前禁用的提示；隐藏后无透明点击/Tab 对象；反向恢复自然；首卡轨迹和返回保持。
