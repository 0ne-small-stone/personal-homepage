# P01 · 玻璃环境亮面分布

日期：2026-10-08。P01 / R01、R12 / U03、U05 / T03.05。执行：首页开发。

## 本轮任务卡

- 来源：共享工作区 `docs/design/iterations/u03-p01-2026-10-08-15.md` 的设计复核及 [SYSTEM](../SYSTEM.md)。当前机制保留，最终视觉未通过；公开推送的授权问题仍待回复。
- 唯一变量：玻璃反射环境中的亮区、过渡区、暗区分布。目标是一侧外缘有渐弱亮面，另一侧留暗；内孔和手机厚度面沿表面出现连续明暗。
- 保持固定：几何、相机、章节姿态、折射位移、RGB 三采样、Fresnel 曲线、反射亮度上限、关闭 Bloom。
- 范围：增加玻璃专用 Environment / Lightformer 组合，并把该环境接到增强材质。原 SceneLighting 继续服务其他物体，不修改项目、白墙或 DOM。
- 复用：Drei Lightformer / Environment。矩形亮面使用程序化灰度衰减，没有下载 HDRI，没有新增 AI 素材；与页面背景无关。
- 旧版：源码基线 `b27cab4`，修改前的生产产物另存于忽略的测试目录；不以重新渲染旧环境参数代替真实旧版。
- 验证：同 viewport、DPR、相机和四元数的桌面/手机首屏旧新对照；独立固定项目姿态；实际指针小幅转动的首/中/末帧。仅做一批改动与一次确认。
- 通过条件：背景控制区不变化；新增脚本/资源错误为 0；透射仍在；反射呈现明暗而非均匀灰条。若固定 shader 裁切等限制使目标未达成，交回诊断，不在本片改曲线。

## 实际改动与参数归属

增加 `GlassReflectionEnvironment.tsx`，复用 Drei Environment/Lightformer，为玻璃单独生成含灰度衰减的灯箱环境。GlassTriangle 创建独立 Scene，GlassOptics 只改环境来源；几何、GLSL、相机和所有章节姿态函数与旧版哈希相同。共享 SceneLighting 未修改，未下载 HDRI、引入依赖或打开 Bloom。候选数值集中登记于 SYSTEM 9.3。

本机新产物入口：[首页预览](http://127.0.0.1:4321/personal-homepage/)。旧 `b27cab4` 产物在修改前复制到忽略目录，采集时通过独立本机 4332 服务；证据同时保留旧新版本，不用改变新代码参数假装旧版。

## 未通过原因与下一步边界
