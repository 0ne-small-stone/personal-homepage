# U03 / P01 · 55 首页只保留中央三角体

**状态：55轮平涂实现曾完成；用户随后要求恢复玻璃与柔光，现行外观由56轮接替。**

## 用户要求与概念

2026-10-13 用户最新要求：“去除全部的物理引擎的效果 仅保留中间的三角体”。这条覆盖此前对物理光传输、折射、色散、散射和柔光的偏好。首页回到更克制的构成：黑色空间中的一个中央实体三角体；形体本身仍可通过滚动/指针产生既有姿态变化，但不再以光学模拟解释它。

该轮曾实际实现并验证；用户在查看后补充要求恢复三角体玻璃质感和柔光。55轮画面与构建信息仅作历史记录，当前玻璃与柔光以[56轮](u03-p01-2026-10-13-56-glass-glow.md)为准。

本任务只收束中央三角体的呈现，不推进全屏展开、The Wall、加载美术或其他首页功能。留存的既有品牌、章节和真实栏目入口继续工作。

## 视觉与技术交接

- **关闭物理光学：**运行时不挂载 `SpectralTransport`、`PrismBeam`、`GlassOptics`、`MeshTransmissionMaterial`、`GlassReflectionEnvironment`、`GlassEdgeLight` 或 `GlassGlow`。不出现白光入射、折射光、彩色分散、焦散、体积散射、反射采样或边缘柔光。
- **关闭流体模拟：**移除首页运行时的 `BlackFlowLayer` 与 `BlackFlow` GPU 速度场/畸变合成。此处所说“全部物理引擎效果”同时覆盖这套交互式流体模拟；不以 CSS/Shader 光带替代。
- **只留形体：**复用现有实心圆角三棱体几何、中心锚点、`scale=.5` 与原旋转输入；以 `MeshBasicMaterial` 的中性 Codex 灰 `#454545` 平涂，不使用透明透射、反射、环境映射或发光。章节交接期间保留现有显隐门禁，形体不跑出墙面。
- **控件与文案：**删除只控制玻璃渲染质量的“光影细节”按钮；移除为遮挡光束添加的 radio 章节文字径向暗衬。保留暂停动态、减少动画、普通浏览/失败降级。加载提示由“正在准备光与玻璃”改为“正在载入空间”。
- **页面范围：**保留黑灰砖格、字标、导航、目录、作品卡、常用网站、音乐章节、The Wall 及其既有交互。保留 `SceneLighting` 给其他三维场景对象使用；三角体使用不受灯光影响的 Basic 材质。
- **渲染层验证：**若移除 `BlackFlowLayer` 让 R3F 恢复自动渲染，需实际确认相机 layer 0/1 的作品前景仍按原顺序绘制，墙章节可读且无穿层；不要仅凭构建通过判断。

既有物理组件和调研记录保留为历史证据即可；本轮以不从首页运行入口引用它们为验收边界，不进行大范围删除或改包。

## 交付验收

1. 首页初始场景只有中性灰中央三棱体，无任何入射/折射/色散/光晕或流体畸变。
2. 中心、比例、圆角、厚度与原几何一致；指针/滚动姿态、暂停/继续、减少动画和墙章节显隐规则仍工作。
3. 删除“光影细节”，保留其他有效控件与加载/错误降级；桌面和 390px 窄屏均无重叠或溢出。
4. 作品图片卡、导航、页面真实内容、The Wall 和返回继续工作；特别核验移除手动后处理后 layer 0/1 排序。
5. `npm run check`、生产构建通过；构建产物不含首页加载的光传输 Worker/光谱缓冲及 BlackFlow 模拟。实际性能变化只记录本机观测，不推断真机 FPS。
