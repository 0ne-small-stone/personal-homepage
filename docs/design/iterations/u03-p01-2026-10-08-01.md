# U03 / P01 / 2026-10-08 / 第 1 轮：LSSH Logo

## 品牌核心

用户要求五个不同 Logo 方向供选择。网站唯一名称为 **Little Stone Still Here**，简称 **LSSH**。这一轮验证标志的构形概念；站名、单色与对照尺度固定。既有 UI 与服务不变，尚未选择正式标志。

品牌命题沿用 CONCEPT：人可以不在线，留下的知识、作品、声音和回应仍然使他被感知。视觉性格沿用 SYSTEM 的圆润、克制与迷幻、辽阔、温柔。歌曲和专辑提供概念起点，本轮不新增歌词，也不引用官方标志作为轮廓。

关联 U03/P01、R01、T02；P02 与全站导航为后续使用场景。统一映射仍由 docs/README 维护。

## 视觉哲学：Quiet Presence

一个小的实体可以让周围的大块空白拥有尺度。构图把重量集中于很少的轮廓，边界有轻微的不对称，使形体接近被时间磨圆的东西。精细调整曲率与重心，让安静来自比例，而非把所有细节都抹掉。

黑色作为未被照见的空间，浅色只描述能够被感知的部分。负形承担穿过、隔开、相遇的关系；去掉解释文字后，形体仍须完整。每处开口的宽度都应经过小尺寸检查，避免概念只能在大图里成立。

重复意味着仍有回应。线的间隔、转向和终止点经过谨慎排列，让回声保留一个明确的来处。静态形态首先独立成立，运动只作为之后可延伸的可能，不用动画弥补一个模糊的符号。

文字承担身份，图形承担记忆。英文全名保持自然大小写，LSSH 保持大写；字距和图文间距经对照微调。中文说明只是评审注释，不构成新的中文站名，也不进入标志本体。

五个方向采用同一背景、字标与展示条件，逐一观察轮廓、重心、反白及缩小表现。工艺上的重点是曲线接续、空隙和光学校正；这一轮只确定有潜力的方向，后续再针对选中的标志精修。

## 五个候选

| ID | 名称 | 构形与含义 | 与既有概念的联系 |
| --- | --- | --- | --- |
| A | Still | 被磨圆的石块低处留下一道水流痕迹；流动经过，石头仍在 | Little Stone、持续在场；倾向个人身份主标 |
| B | Echo | 一个小石核与两道错开的回声；外圈留有出口 | 声音离开后仍被另一个人接住；倾向感性、音乐性的身份 |
| C | Through | 柔角三角体被一道转向的光切开；形体与路径互相定义 | C02 光提供方向；倾向首页空间及动效的连续性 |
| D | Threshold | 墙的实体退让出入口，小石留在开口里 | C05 回应使边界可读；倾向“有人在这里”的空间识别 |
| E | LSSH | 四个首字母组成紧凑的双行字母标，S 的转折采用一致曲率 | 名称本身成为图形；倾向清楚的作者签名 |

以上是本站设计延伸，不宣称是专辑的唯一含义。五个方案不代表五个新品牌名称。统一参数和正式使用规范待选择后写回 SYSTEM，本轮不另立品牌规范文件。
