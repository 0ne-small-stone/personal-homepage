# U13 · P17、P06 · T13.10 正文链接

2026-10-09 第 1 轮。P17、P06 / R13、R10 / U13 / T13.10。唯一主要变量为正文链接编辑和保存往返，执行者通过，用户体验待反馈。

## 依据与复用

沿用 P17 原生 CMS 与 AD01 管理控件，ui-ux-pro-max 用于入口、文字选择、目标地址和提交反馈核查。使用原生 Link、地址输入、✓/Enter、Editor/Source、Save；只补两处中文正文说明，明确工具条应用后还需 Save。没有新 UI 主题、图形、字体、动效或依赖，设计资源新增 0。

## 实例与证据

原生控件实际创建站内相对链接及外部 HTTPS 链接，已有地址预填正确；改地址 Enter 应用、改链接文字保持地址。模式往返、真实 Save 和刷新后文字/地址均保留。网站原生草稿实际点击到正确阅读样稿及官方富文本文档；最后通过 Source/Save 完整恢复原稿，两端测试段消失。固定稿及集合新建均显示链接说明。
