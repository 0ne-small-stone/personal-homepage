1. 在用户同一完整首页复现明显正面→斜视→停止→反向输入。区分玻璃真实旋转、光学采样调度、完成结果姿态和最终合成。

4. 修姿态同步后再看色散与光晕。检查光谱到显示的clamp/曝光、叠加顺序、章节透明度和柔光被遮挡/洗白的问题。颜色应来自波长传输，光晕应从真实受光/发光区域柔和衰减；不得恢复旧彩色贴片、假渐变接缝或硬光片。

## 可见验收门槛

- 转动中光路能响应当前姿态；需要渐进收敛时及时撤销不匹配的旧结果，不能长时间呈现一条固定旧光。停止后能收敛到当前姿态，反向也成立。
- 固定世界入射源保持；出射方向/光斑/分色随姿态有物理合理变化。不能仅转模型、平移光纹或让同一张贴图追随。
- 覆盖滚轮旋转输入。玻璃仍承担可见旋转主视觉时保留可读光效；原先rendered.index进入首卡即把光谱和柔光归零的统一门控不得造成转动段无光。按实际前景遮挡及主视觉退场衰减，避免穿过卡片/文字。
- 首屏正常显示比例可辨色散；玻璃及邻域有柔和光晕，保留黑底和玻璃层次，不泛白、不出现硬光片。
- 桌面至少两个明显不同姿态、暂停/继续、窄屏、去首卡再返回集中验证。原始失败和修复后结果分开留存。
- 工程提交证据包含实际预览URL、bundle、针对性测试与构建结果。独立设计验收后才重新交用户；不把执行者判断记为用户通过。
