## 1. 本次授权与基线

用户在设计对话要求继续首页缺口队列，本轮只推进 F02 全屏展开。该指令允许开始下一功能，不将此前 F01 的设计复核冒称用户审美通过。

先前读回「首页开发」用户指令：**“去除全部的物理引擎的效果，仅保留中间的三角体”**，55轮已完成中性平涂候选。随后用户在该对话进一步纠正：**“三角体的玻璃质感柔光效果怎么没了，加回来”**。后者为当前最新材质依据：先收束玻璃质感与柔光恢复，再接本功能。保留其最终材质、中央锚点、半尺寸、厚度与旋转输入；不恢复光谱传输、入射光、彩色分光或流体模拟。旧清单关于“真实光学继续接入”的内容不再作为当前施工任务。55平涂只保留为对照基线，不是F02最终美术目标。

F02 的场景纹理采样是转场合成，不需要恢复物理光谱模拟。F03 加载、F05 背景、F06 控件、F07 切页、F08 留言、F09 音景继续分项；F04流体按最新撤除基线暂缓。独立音乐页不在本轮范围。现有留言未配置状态保持真实。

## 2. 动作与概念

**观看一块留在黑暗中的小石，逐渐进入它容纳的空间。**此前观看别人的作品；跨过它的表面以后，访客可以在墙上留下自己的痕迹。

焦点动作只有一个：末张卡离开后，三角体表面成为一个可辨识的空间窗口，轮廓及侧面持续铺开，内部的同一面墙接管全屏，随后墙升起。形体变成空间的边界；不能用三角体淡出加白色底板淡入代替。

采用已经核对的 ALCHE 轮廓/侧屏展开机制。来源为 [17 轮源码研究第 5 节](evidence/alche-motion-2026-10-08/source-timeline-report.txt)，不是其末张媒体曲面铺屏机制。已有截图仅作某一时刻证据，不能单凭文件名推断完整动作。现成工程能力为 R3F/Three、现有 render target 与共享滚动状态，不增加动画引擎或网络素材。

## 4. 参数与实施边界

**参数唯一来源仍为 SYSTEM 9.2.1、9.2.4、9.2.5**，本文件不另设冲突数值。先采用现有 prepare → expand → wall_reveal 区间与各自追随系数；这些原规划区间尚未接入当前实现。若在真实体验中发现空滚动，应在同一轮集中修正并把最终数值登记到 SYSTEM。

- 当前代码 `motionRange('wall')` 直接接 works_outro，缺 prepare/expand；需接齐共享通道、文档 spacer、章节目标/返回恢复和诊断，不只增加一个覆盖层。
- 原站几何坐标不能直接乘到本站半尺寸实心三角体。从当前 mesh 的实际几何/投影起势，展开至覆盖四角并留安全余量；不能在起势帧跳回旧全尺寸/三角环。
- 墙对象和砖纹只有一份真实场景数据。先由现有 renderer 对该场景离屏取样，窗口与全屏均使用同一结果；单 Canvas、单 RAF。需要额外 target 时记录大小、更新范围、释放方式。无需流体、光谱或高采样收敛。
- 先让内部低亮空间可见，再在全屏后升起墙；不要让整个展开阶段都采到空黑纹理。升墙前后同一组砖缝应可追踪。
- 反向、中断、快滚、hash/返回初始化均从共享进度恢复，不排队播放不可逆 tween。缩放与旋转手机适配后也必须覆盖四角。
- 减少动画/普通浏览保留完整语义内容，省去大幅空间展开；图形失败不遮挡入口。顶栏、文本、CTA 不进入图形扭曲或采样层。
- 展开覆盖导航/底部控件所在区域时，前景颜色随实际背板明暗交接，保持可读。不能等到墙阅读 DOM 出现才切主题。此为转场内的对比度门禁，不扩展 F06 按钮美术。
- 不恢复已撤光谱/入射/分光/流体效果；最新要求恢复的玻璃质感与柔光保留，并与轮廓展开连续交接。不搭新写实展厅，不更换墙材、字标或增加过场文案。使用现有平整哑光大砖与抽象黑灰空间。
