## 样本方法与边界

沿用 [19 轮 QA 方法](../../../tools/qa/p01-first-card.cjs) 的 Playwright 响应覆盖和唯一 neutral 正则匹配，在现有 `http://127.0.0.1:4321/personal-homepage/` 上创建无界面的 Chrome 页面。无需新增应用依赖，没有启动新服务或访问原站。

只在 `**/HomeJourney.*.js` 的浏览器响应中执行以下覆盖：

1. 双方相同地把现有 `quaternion.slerp(...)` 测试替换为固定四元数。正面为 `[0,0,0,1]`；35° Y 为 `[0,0.3007057995042731,0,0.9537169507482269]`。
2. 旧样本保留 `mix(transmitted, light, 0.015 + edge * 0.82)`；候选改为 `mix(transmitted, light, 0.06 + edge * (0.835 - 0.06))`。两者的掠射权重上限均为 `.835`。
3. 两方共同启用已有只读 `motionDiagnostics`，通过 `lssh:motion` 读回相机、玻璃投影、原始及平滑进度。控制 `performance.now()` 后推进 80 次 50ms，每次等待两次原生 RAF，随后采集。没有调用产品暂停按钮，没有调整其他颜色或亮度。

Chrome `154.0.8037.98`，SwiftShader 软件渲染，DPR 1。桌面为 1440×900；手机布局为 390×844。软件 GPU 与模拟手机不是性能或真机触摸证据。

六张图读到的原始主包均为 `HomeJourney.BQGDYnq6.js`，SHA-256 为 `84cb66cb87b519434377207329fb163b454099a8ab2a69a928ff244266768b70`。没有发生需要重开样本对的 bundle 变化。此 SHA 是本次实际服务产物，不借用第 19 轮提交号冒充当前版本。

## 同条件与像素证据

每对比较原始 bundle 与本地资源哈希，并将读回的相机、玻璃锚点/四元数/比例/投影边界、视口/DPR、原始/平滑进度逐字段比较，三对完全一致。桌面首屏相机为 `[0,0,5.7]` / FOV 42.25；桌面 550 为 `[0,0,6]` / FOV 46.25；手机为 `[0,0,5.7]` / FOV 69.95384615384616。

像素检查直接比较原始 PNG 的 RGB，无重采样。玻璃投影边界外扩 2px 后，对外部区域作完整扫描；另明确标出玻璃外纯背景控制区。边界与所有统计见 [pixel-comparison.json](evidence/u03-p01-2026-10-08-23/pixel-comparison.json)。

| 条件 | 纯背景控制区 `[left,top,right,bottom]` | 控制区变动像素 / 最大通道差 | 全部玻璃外变动像素 |
| --- | --- | --- | --- |
| 桌面序章 | `[1040,200,1400,700]`，180000 像素 | 0 / 0 | 46，全部位于 `[52,645,64,662]` 的向下箭头 |
| 桌面 550 | `[1040,200,1400,700]`，180000 像素 | 0 / 0 | 0 / 1090208 像素 |

两个首屏的完整外部零差异门禁明确为 **false**，不能删掉这些差异后宣称全外部一致。差异位置对应 `.home-scroll svg` 的既有 `scroll-hint` CSS 动画；本轮控制了 JS 的 `performance.now()`，没有冻结 CSS document timeline。该 DOM 箭头不进入玻璃的场景缓冲，已核对其位置在玻璃范围以外。桌面 550 这一对则满足全外部像素完全一致，可独立支持本次材质未通过的判断。

玻璃包围盒内的平均绝对通道差分别约 `.080 / .186 / .018`（8-bit 通道值），最大差 `24 / 11 / 6`。包围盒含开口与背景，不能把这些统计直接叫作“玻璃平均亮度”或改善比例。

## 收口与下一步

保留当前应用参数；不因为 `.06` 理论上增加正面反射贡献就接入。此轮反证说明：**单独提高这一基值没有产生目标画面**，不能再将“权重较低”直接写成已定位的唯一根因。

下一步建议先在独立测试中分别观察背景采样、环境采样及最终混合输出，定位近黑来自哪个环节，再选择一个新的材质变量。此诊断本轮未执行；未顺势更换 HDRI、法线或增加第三个参数。现有第 22 轮文字门禁工作独立继续，玻璃最终视觉仍未通过。
