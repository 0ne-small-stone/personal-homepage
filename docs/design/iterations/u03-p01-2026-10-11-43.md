2026-10-11。P01 / R01、R12 / U03、U05、U14 / T03.01、T03.05。对应[GitHub #34](https://github.com/0ne-small-stone/personal-homepage/issues/34)的几何前置。

## 用户要求与依据

用户明确“把玻璃三角环直接变成实心三棱镜”。移除中央孔洞及内孔光，保留当前外轮廓、厚度、统一scale=.5、居中、旋转规则及外缘连续低峰柔光。现行参数唯一来源SYSTEM9.3.10；旧孔洞比例和内缘发光仅作历史记录。

当前GlassTriangle以Shape.holes生成孔洞，GlassEdgeLight/GlassGlow默认有内孔轮廓和innerPlanes。不能只删除holes而继续读取paths.holes[0]，也不能用透明面板盖孔或在中心刷白。

## 一个工程切片

1. 复用现有圆角Shape/ExtrudeGeometry，取消hole及对应Path依赖；实体正背面应完整闭合，外包络、深度、倒角和中心保持。
2. 发光轮廓提取只读取真实外缘，GlassGlow撤innerPlanes与内部距离场；保持现有源强、Gaussian、合成增益、render targets、首卡门禁和资源回收。中心玻璃保留透射，不能变成白色灯牌。
3. 不变更相机、GlassRotation、字标、背景、栏目或音乐实现，不增加依赖。本片不接入白光束、波长色散或扩大旋转角度。

- 读回几何holes=0；从正背两方向沿Z穿过原孔中心，射线应命中完整前后实体面；局部W/H/D与原版一致，实例scale=.5。
- 一批桌面/390 CSS px首屏及原生斜视，确认无孔洞、内壁、内圈柔光、整片泛白或可见光片；保留有深度的透明玻璃。
- 普通/增强、暂停恢复、首卡收光与反向恢复做局部核对；单Canvas、无新控制台错误。
