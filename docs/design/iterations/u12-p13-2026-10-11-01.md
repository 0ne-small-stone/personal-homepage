# P13 / U12 · Echoes 双音源电台首片

2026-10-11。对应 P13 / R04、R12 / U12 / T20.01、T21.01、T25.01；T21.02、T21.03、T25.02分别保留外部依赖和后续验收。本次「音乐电台」对话按用户指令实现音乐栏目，不修改首页场景源码。源码基线为实际工作区`4fed0a7`（42轮首页），保留现有主页与知识库，不回退到旧main。

## 本轮行为

用户要求考拉云盘和网易云两种模式，并指定 Echoes 共享歌单18476425375。音乐页已从待配置占位改为可操作界面：单曲/专辑、搜索、当前曲目和实际音质标签；顶部下载入口直接使用官方`lxmusic://music/search`打开洛雪，用户在洛雪选择该曲目实际可用的最高音质。安装入口用洛雪官方发行页，音源更新入口沿用仓库`洛雪音乐.txt`；原始文件未改动。

本机洛雪下载目录实际读取18首声音玩具FLAC、3张专辑（爱是昂贵的6、劳动之余7、最美妙的旅行5），同时有歌词文件但本轮不导入歌词。解析复用music-metadata12.1.0/MIT，不复制音频、封面或本机路径进网页。索引写入被忽略的`.local-tools/music/catalog.json`；本地监听每5秒观察，连续两次稳定再解析，前台开发页每15秒读取且隐藏时暂停。单次扫描和监听命令已提供，监听本轮已开启；未安装开机服务。

网易云模式进入后挂载官方iframe、auto=0，切出销毁。实际显示Echoes/Pink Floyd，点击原生播放取得音频HTTP206响应，剩余时间显示变化；没有声称26分钟完整播放或全部版权曲目都可用。保留原站歌单入口。考拉没有真实公开音频URL时，播放按钮明确为待连接，目录仍可浏览。跨页持续播放未实现。

## 设计与实际读图

复用CONCEPT的Echoes听音空间、SYSTEM黑灰/圆润克制/苹方与现有HomeLayout，主技能frontend-design。没有新增主题、字体、动画库或下载专辑封面；已下载收藏使用文字首字占位。参数只在SYSTEM的P13首片布局维护。

桌面为当前曲目/目录约1:2两列，手机单列并缩小占位。执行者实际读取桌面、390/320px与网易云原生截图；修正窄屏下载入口挤换行，并把完整330×450px外部播放器缩放到实际可用宽度。320px容器/iframe实测均288px、高约392.72px，右侧列表等控件完整。外部播放器的原生颜色和交互保留，不伪造本站进度。用户审美确认和真机性能另记。

## 考拉阻塞与剩余工作

用户授权新建专用音乐文件夹`LSSH-Echoes`，两次在Nextcloud官方Login Flow v2页面完成授权。首次身份读回失败后修正OCS状态码解析，第二次仍明确HTTP401/OCS997；因此**文件夹未创建、只读分享未创建、音频未上传**。没有把用户的「已授权」写成云盘已接通。创建/读回代码已准备，但身份前置未通过；没有使用浏览器Cookie、提取账户密码或上传文件。

一次性appPassword只在进程内存。长期凭证保存方案被自动审批拒绝，理由为超出登录、创建文件夹/只读分享的授权范围；未执行且撤回。流程结束申请撤销也遭401拒绝，用户可在考拉安全设置移除两条`LSSH Echoes folder setup`授权记录。浏览器控制工具与备用Windows入口启动失败，未绕过获取会话。

下一片先解决考拉认证接口或通过官方页面完成文件夹与只读分享，再验证真实音频Range/MIME、播放/拖动、失败恢复；优先配置Nextcloud官方桌面同步客户端，分别完成文件上传与公开catalog读取。当前稳定文件检测不能排除暂停的不完整音频，下载完成状态隔离仍待验证。线上自动更新、账号同步闭环、跨页持续播放、推歌审核/写入、真机及大陆访问都不记完成。

本片为本地可体验交付，未推送、创建PR或部署；提交与仓库检查结果在收口后记录于技术PLAN。
