## 2. 一轮的固定节奏

**定义问题 → 查找复用 → 制作最小样本 → 实际操作 → 对照检查 → 保留或回退 → 更新记录。**

| 步骤 | 本轮必须产出 | 可以继续的条件 |
| --- | --- | --- |
| ① 定义 | 一句话问题；页面/控件编号；对应概念规则；本轮变量 | 能指出观察什么才算改善 |
| ② 复用 | 首选候选、具体能力、必要修改；有明显差异时最多补 1–2 个对照 | 有来源，知道如何接入及如何验证 |
| ③ 最小样本 | 一个真实尺寸的局部、一个组件或一次交互；放入代表性中文内容 | 能独立打开、触发、重置 |
| ④ 操作 | 走完触发、进行、完成、取消或失败；涉及输入时覆盖对应设备 | 实际结果可复现，不以静态图代替交互验证 |
| ⑤ 对照 | 相同视口、内容、光照与进度下的前后图或录屏 | 能分清本轮变量造成的变化 |
| ⑥ 决定 | 保留、修改或回退；写出依据和剩余问题 | 关键功能无退化，概念目标有可见体现 |
| ⑦ 归档 | 参数、来源、证据路径、状态和下一步 | 下一个人能接着做，不必重新猜意图 |

单轮以一次评审能看完为尺度，通常只涉及一个控件、一个素材用途或一段动作。若同时更换字体、布局、贴图和转场，应拆轮。普通适配、错误修复和参数调试自主推进；审美分歧保留可体验对照供用户选择，不要求每个按钮逐个审批。

## 3. 从页面功能到细节的顺序

下列顺序用于每个页面。已经通过的成熟组件原生行为无需重新发明；检查本站改动及其连接处。

| 阶段 | 最小切片 | 验证方式与通过条件 | 未通过时回到哪里 |
| --- | --- | --- | --- |
| A 功能与来路 | 一页线框、主要任务、入口与出口 | 走通正常、直接访问和返回；能辨认要做什么 | 调整功能分组或导航 |
| B 内容与选图 | 一个真实条目及其封面/材质；无素材时注明待提供 | 实际页面尺寸检查构图、信息、来源和裁切 | 更换候选或调整裁切 |
| C 静态构图 | 一个桌面和一个手机画面 | 无动画也有层级、留白、可读内容及明确操作 | 调整布局、字级、明暗 |
| D 单个控件 | 一个按钮或一组同类筛选的完整状态 | 鼠标、触控、键盘触发正确；焦点与结果清楚 | 修复控件，不重做整页 |
| E 单段运动 | 一个触发到落定的动作 | 中途停止、快速反向、重复触发、减少动画均可用 | 调整动作映射或删除无意义运动 |
| F 页面组合 | 已通过的内容、控件和动作放入一页 | 没有互相挡住、争抢输入、重复动画或失焦 | 处理组合问题 |
| G 跨页旅程 | 一条真实浏览路径 | 进入、退出、浏览器返回、刷新和深链状态一致 | 修正页面关系或历史恢复 |

所有页面先有可用线框。每个局部完成 A–G 后才扩大使用范围；无需等整站所有静态画面都完成才验证最关键的空间动画。

## 4. 选图与素材的迭代方法

1. **写用途卡。**指出页面位置、需要表达的事、宽高比、文字安全区、是否需要透明/平铺/法线贴图。例：墙面需要近看有粉刷质感、远看砖缝克制、黑白状态属于同一块材质。
2. **先找现成。**从真实个人素材和[现有候选](REFERENCES.md)开始。每个用途先比较 2–3 个有效候选；来源、作者、许可和能否用于目标用途可查后再进入采用阶段。
3. **同条件比较。**封面放进同一张卡片，墙贴图放进同一面墙；同时看完整图、实际裁切、手机裁切。只看图库大图不能决定采用。
4. **一次只改一项。**先构图/焦点，再曝光或色温，再尺寸与压缩；保留原图。墙材质分别检查砖尺度、接缝、受光和纹理重复。
5. **验收并登记。**检查主体不被裁掉、文字清楚、内容真实、加载失败有去向；记录派生文件、参数、替代文本与采用原因。
6. **确有缺口再二创。**写明哪些现成资源经过何种尝试仍不满足要求，以及仅需新做的部分。

原型可以使用明确标注的示例媒体，正式个人作品必须换成真实内容。素材尚缺时先推进结构与控件，不以无关图库照片充当个人摄影。

## 5. 每一个按钮的迭代方法

每个交互控件都有稳定编号。同类控件可以共用一个组件状态样本，但页面上的每个实例仍需检查其文案、目标和焦点顺序。基础编号见[概念施工说明](CONCEPT.md)。

### 控件卡最少字段

| 字段 | 必须说清楚的内容 |
| --- | --- |
| 编号、页面、位置 | 如 H02：首页中央棱镜 |
| 用户意图与文案 | 想做什么；可见名称；辅助技术名称 |
| 语义与触发 | 链接还是动作；点击/键盘/触控如何完成 |
| 状态 | 默认、悬停、焦点、按下；按需补选中、忙碌、不可用、成功、失败 |
| 结果和退出 | 目标地址或状态；焦点去向；取消和返回如何恢复 |
| 主题联系 | 承担显露、靠近、展开、关联、回应、返回中的哪一种；纯工具动作可不加装饰 |
| 复用与参数 | 使用哪个成熟组件、规范变量、局部修改 |
| 证据 | 状态图、操作记录、结果；不适用的状态说明原因 |

### 已填写的施工例：H02 棱镜入口

- 目的：启用靠近留言墙的控制；文案“走近留言墙”，辅助说明“选择后可滚动靠近，也可使用靠近按钮”。
- 语义：有明确名称的按钮，图形提供外观；点击或 Enter/Space 从远处进入已选状态。缺少图形运行环境时提供去留言墙的普通链接。
- 状态：默认细轮廓；悬停/焦点增强边缘并显示同一提示；按下立即反馈；选中后光聚向墙面并出现控制区。焦点使用规范描边，不用发光替代。
- 结果：只激活控制，不立即改变地址；焦点转到控制区的“靠近”。再次触发保持已选，避免重复绑定滚轮。
- 退出：Esc/取消恢复首页远处和 H02 焦点；到达后进入留言页，焦点到留言标题。
- 证据：默认/焦点/选中截图；键盘激活、取消、重复点击、图形失败各一次记录。
- 当前状态：已定义，未制作、未验证。

## 6. 每一段动画的迭代方法

先制作起点、终点和三个中间帧，再连接运动。空间靠近使用进度 `p = 0 / 0.25 / 0.5 / 0.75 / 1`；时间动画用等比例时间检查。进度参数不是已经耗费的秒数。

每段动作写明：**原因、受影响对象、不动的锚点、输入来源、进度/时长、结束状态、中断处理、减少动画替代**。初始参数取[设计规范](SYSTEM.md)。

最小检查集：

- 正向走完一次；反向或关闭一次；在中段停下再继续。
- 快速重复触发不会排队播放旧动作，界面状态以最新操作为准。
- 五个检查帧都能找到退出，必要文字和焦点可见。
- 鼠标、触控板和手机替代入口不会抢走正文、表单、播放器的输入。
- 减少动画与图形失败后仍能到达相同功能。
- 在实际可用设备记录短录屏和帧时间观察；卡顿时先降辉光、采样和纹理负载，再重新检查。

首页靠近的第一轮只验证“墙如何接近”，通过后再加受光，再加文字状态与路由。色散、微粒、声音分别作为后续独立迭代；只有确实改善表达才保留。

## 9. 通过与返工规则

每轮只检查受影响范围；进入页面组合或跨页阶段时扩大检查。基础视口：390×844 手机、1440×900 桌面；涉及布局重排时补 768 宽，涉及边界时补 320 宽或横屏；涉及文字时检查 200% 缩放。模拟手机与真机体验分别记录。

| 检查维度 | 通过依据 | 必须返工的情形 |
| --- | --- | --- |
| 功能 | 能完成当前任务，去向与反馈真实 | 死按钮、错路由、丢输入、伪造成功 |
| 概念 | 至少关联一条概念规则，并有可见行为 | 只有专辑符号，没有导航、阅读或回应的作用 |
| 可读与可控 | 关键文字、焦点、退出与替代入口可用 | 动画遮字、失焦、滚轮被困、手机只能猜手势 |
| 连续性 | 关闭/返回恢复合理位置；直接访问也成立 | 为读内容必须重复经历完整开场 |
| 复用与维护 | 来源清楚；保留成熟行为；改造范围可解释 | 候选被写成已接入；无需要地重写基础组件 |

可量化检查由实际结果决定；“迷幻、辽阔、温柔”的审美判断用静止、中段、阅读三个画面对照，并记录理由。证据足够后停止重复测试，提交这一小步，再领取下一步。
