## 实现与复用

沿用 Starlight 的 docs 集合、Markdown frontmatter、原生侧栏分组和 Pagefind；不新增集合、主题或依赖。现成组件能完成科目目录和阅读页，但不能直接把原始 PDF/两个 TXT 整理成统一条目，因此补充一个可重复运行的目录导入工具。它只从已分类清单生成 Markdown 和对应表，原件核对可通过 `--source` 读取，不复制或修改原件。

资料与笔记保留 entryId、kind、topics、related，新增来源信息按 pdf/link 分别校验必填字段。科目内章/讲使用原生侧栏 order，学习总览按科目及自然数字顺序排列。每页提供普通同科目链接，不代表已实现反向引用或筛选返回恢复。原先三个示例转为草稿，不进入列表、生成路由或搜索结果。

原生侧栏使用当前已安装 Starlight 0.42.5 的 label + items + autogenerate 配置；首次检查指出旧式 label + autogenerate 已不支持，修正后类型与构建通过。导入结果全部留在原生内容目录，构建流程仍由 Astro/Starlight 管理。
