## 改动与边界

复用现有 KnowledgeTypeFilter、publishedKnowledge 与 topics 字段，增加原生主题 select 和“清空筛选”。选项是同一批公开内容的主题去重、中文/数字排序，保留所有类型的主题；每个结果必须同时符合类型与所选主题。多主题用精确数组成员匹配，不按科目目录、字符串包含或人工清单推断；条目不重复，未分类只在全部主题视图出现。

topic/type 写入 URL；选择一个只改变一个，清空删除两者并保留其他参数与锚点，随后焦点回到可见“全部”类型。popstate/pageshow 恢复视图，继承已有 history.state。未知值只回退对应字段并解释，零结果保留当前条件。一条原子 status 汇报主题、类型与数量；无脚本保留全量静态链接并明确筛选不可用，不假装 query 已应用。

原生控件覆盖需求，只补已有筛选器的局部状态与数据绑定；新依赖、素材、集合为 0。44 个既有内容文件及草稿“吃吃吃”未改动，正式文章仍为 0。原始资料与忽略的本机 PDF 副本保留，未新增上传。共享首页开发及设计工作区未修改；P03 设计第 3 轮整体构图不在本轮合并。
