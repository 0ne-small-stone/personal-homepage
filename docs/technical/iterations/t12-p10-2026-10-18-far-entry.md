# P10 / T12 无限空间远端补图（2026-10-18）

用户反馈“无限空间里有一些图片是从近端刷新而非最远端刷新”。接续正式main cc7a96d，关联P10/R06/U10/T12、T26、T27；仅在独立发布副本修正空间候选生命周期，共享根旧HEAD/WIP、其他栏目和现有UI/UX保持。沿用图库发布授权与PR/Pages流程。

同日用户明确持续向前、反向和平移“都有”。统一按画面中央近端不新建处理；反向不设置近端例外，已经出现的世界卡位保留，视野新露出的卡片只能在远端或边缘窄带进入。

## 判因与修正范围

当前每次镜头变化都重新按近远排序、投影碰撞和同图去重挑选候选；没有区分“已经在场的卡片”和“刚被重新选中的卡片”。因此被剔除的世界卡位可能到近处才第一次/再次加入，即使纹理早已加载，也会产生近端补图观感。对象池复用只保存世界key，不限制新key的入场深度。

沿Impeccable局部修复约束处理：

- 保留已经在场的卡片优先级，避免新候选替换已有卡片、同图代表在近处来回跳换。
- 稳态中央新卡片，仅从深度220–260的远端消隐带加入；原140–260距离衰减、近端消隐、照片尺寸、原图比例及世界种子/坐标保持。反向不设近端中央补图例外。
- 初始化/进入镜头交接及视口比例改变维持既有场景铺设，收回总览不重铺；后退和有效平移允许图片从屏幕边沿15%窄带自然进入，不能借边沿条件在中央补整张图，纯前进不借微小视差补近图。实际检查反向覆盖不出现空场。
- 生命周期信息随既有7³区域缓存裁剪、重新进入总览后重置。沿96候选/640对象池、按需绘制、101张内容及已有同图分散规则，不加常驻计时/依赖/新图片。
