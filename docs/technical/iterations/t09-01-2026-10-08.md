## 改动与边界

现有资料/笔记已声明 `related`。原生 Astro reference 按集合 ID，当前字段按业务 `entryId`；本轮补索引和发布过滤，使用目标当前原生路径、真实标题及类型，不新建集合或迁移地址。知识 ID 在已发布/草稿范围唯一且必填；已发布来源未知关联报来源文件与目标 ID，草稿中的未完成关联暂不阻止构建。草稿目标隐藏、重复/自指省略，保持声明顺序。

新增静态“关联内容”nav，使用普通链接、现有发布前缀和 Starlight 语义颜色，放在正文之后；PDF 阅读器仍在前，关联不随说明折叠，无公开目标不显示空区。手写 Markdown 和外部笔记跳转保持。Pagefind 忽略关联导航，避免目标标题变成本页正文命中。文章阅读返回增加关联链接焦点恢复，PDF 页码等状态留给 T26.01。

仅为已有功能文章声明正文中已经存在的两条验证关系；没有新增正式文章，也没有自动推断引用或反向关系。新依赖、CMS 配置、路由和工作流触发范围均未增加；既有 CI 内容测试一步纳入关联规则。
