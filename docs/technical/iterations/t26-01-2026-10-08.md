# T26.01 三类列表与阅读返回

日期：2026-10-08。P03、P05、P06 / R12 / U09、U14 / G04、K03、K04-native / T26.01。基线 T07.02 `8656c32161aad0301a195fcb2e1c7c854ce05735`，分支 `codex/t26-01-reading-return`。仅此切片通过执行者验证，用户体验待反馈；整站、整页视觉和部署分别验收。

## 改动、依据与范围

沿用现有 ArticleNavigation 和 article-navigation，已发布路径清单扩展到三类内容；普通点击才记录同标签页来路，外部笔记只登记已发布原地址。返回静态链接在正文/PDF 前呈现，有来路则回列表、搜索或阅读页；直达资料/笔记回相应类型学习总览，文章回文章列表。保留既有存储键、20 次记录上限、原生 URL/history/Pagefind，不引入新路由或阅读状态服务。

改前[实测](evidence/t26-01-2026-10-08-baseline.json)：资料无返回链接；浏览器后退保留 478px 滚动，未恢复条目焦点。PDF 3 页/150% 重载回到 1 页/page-width，应用的强制 fragment 覆盖原生 ViewHistory。现删除该强制参数，复用 PDF.js 6.4.299 指纹历史。vendor 文件、原件、忽略的本机 PDF 副本、44 份既有内容与草稿“吃吃吃”均未修改或上传；新增依赖、素材为 0。

实现中发现同址侧栏链接会抢占列表焦点，改为记录实际来源区域、仅恢复可见链接；来源区域为固定白名单。章节锚点可另建历史条目且 state 为空，因此同一文档保留自己的来路，阅读地址变化时跟随真实来源 href 并使用一次性同源交接恢复来源。新标签/修饰键不记录来路，不继承旧阅读返回。普通浏览仍保留原生后退/前进；外部网站不注入任何本站控件。

## 实际验证

- 类型检查 **26 文件，0 errors/warnings/hints**；生产构建 **51 页**通过。已有 MarkdownContent 与 404 提示仍为非阻断信息。
- [30 组证据](evidence/t26-01-2026-10-08-browser.json)：**29 组 Edge 行为/状态 + 1 组静态核对**。静态预期独立解析现有 YAML，全部 **37 个站内详情**有正确类型回退；36 PDF 返回在阅读器之前，URL 无强制 zoom。3 外部笔记和 4 草稿分别排除该站内核对范围。
- 从概率资料组合返回：类型/主题、其他参数、来源条目焦点与 **478 → 478px** 位置恢复。PDF 笔记组合保留参数/锚点及笔记选择；文章组合、原生文章/标签列表、刷新和前进后退回归通过。
- 实际 6 页 PDF 设为 **3 页/150%**，父页刷新、浏览器前进后退及“资料 → 关联文章 → 返回 PDF → 原列表”均恢复；35 页 PDF 笔记 **5 页/125%** 重载与返回通过。嵌入 PDFHistory 实读为 false，阅读操作不增加父页历史。
- 正文、关联、侧栏拥有同址目标时回到实际来源区域；文章目录章节后能一次回列表。Pagefind 资料/笔记原词与结果焦点恢复；文章章节结果 → 另一目录章节 → 刷新 → 返回搜索也通过。原生标签“阅读与整理”的来路文案、刷新、位置/焦点正确。
- 外部笔记 href 保持 `https://note.noughtq.top/algo/ads/`，本站浏览器后退恢复列表/焦点。此项用浏览器受控替身隔离外站网络，**只验证导航与恢复，不宣称外站或大陆可达性**；未写入外站内容或发布替身页面。
- target=_blank（带可复制 sessionStorage 的 opener）和 Control 点击均使用自己的详情回退；已有旅程之后直接粘贴地址不借用旧来源。
- 390/320/768 宽无父页横向溢出，返回目标实际高 44px，Tab/Shift+Tab 有 2px 实线焦点；返回文字浅/深对比 **6.48 / 10.85**，沿用苹方优先字体和减少动画偏好。五张[设计截图](../../design/iterations/u09-p05-p06-t26-01-2026-10-08-01.md)已实际查看；真机/屏幕阅读器另验。
- 无脚本有真实类型回退与 PDF 原文件链接，总览明确显示全部 40 条；sessionStorage 禁用或畸形时静态回退正常。localStorage 禁用仍可渲染 PDF，但不保存历史；新浏览器上下文初始 **1 页/auto**，不会借用旧页码。被监听主浏览器的未捕获错误为 0。
- 本机静态产物 **563 文件、546,396,120 字节**通过显式 `--local-preview` 检查；公共目录 51 页检查通过。本机 PDF 不进入发布产物，正式 CI 使用干净构建另验。
