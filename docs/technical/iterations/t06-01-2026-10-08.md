## 用户验收与复现

1. 打开[干净筛选入口](http://127.0.0.1:4366/personal-homepage/knowledge/?type=resource&topic=%E9%98%85%E8%AF%BB%E4%B8%8E%E6%95%B4%E7%90%86)，应只有一份 PDF 功能样本。点开直接呈现已渲染内容。
2. 改第 3 页、125%，刷新仍保持；点“返回学习总览”保留资料/主题和原条目焦点，再进入仍保持阅读位置。
3. 搜索“阅读验证”；点“下载 PDF”可独立阅读四页文件；“全屏阅读”打开完整 viewer。展开“资料说明与来源”核对作者、许可和 65,959 字节。
4. 同一[详情](http://127.0.0.1:4322/personal-homepage/knowledge/resources/reading-guide/)可在原预览体验；4366 的旧私人 PDF 无附件为真实状态。测试手机放大时允许 PDF 内滚动，不应推动整页横向溢出。

正常干净工程：`npm run check`、`npm run build`、`node tools/ci/dist.mjs`、`node tools/verification/public-pdf-check.mjs`、`node tools/verification/public-pdf-guards.mjs`。本机有副本时 dist 校验仅显式 `--local-preview`。可用 `node tools/verification/public-pdf-fixture.cjs` 创建新隔离快照（同名已存在则拒绝覆盖）；浏览器工具需独立设置 `PLAYWRIGHT_PACKAGE` 后运行 `node tools/verification/public-pdf-browser.cjs`，不向网站安装测试依赖。

4366 为隔离工程原生后台预览，PID 37768；4322 保留原服务，已有其他验收快照不改。截图与验证使用独立 Edge 会话，未操作用户现有标签。
