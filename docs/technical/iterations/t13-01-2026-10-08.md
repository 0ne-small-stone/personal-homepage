## 现成能力与最小适配

`.pages.yml` 配置 Pages CMS 原生固定文件、中文字段、Markdown 富文本/Source 切换；不开放创建、删除、改名和媒体上传。隐藏只读稳定 ID、类型、测试标记，草稿只读开启。`settings.content.merge: true` 使用原生未建模字段保留功能；账号权限仍由 GitHub 管理。

官方源码配置校验及 YAML 序列化基于 `hunvreus/pagescms` 提交 `6f4e860a35d934406580287e7042e5e111e207a1`，其 package 声明 2.1.8、MIT。源码只用于忽略目录内的校验，没有复制 CMS 到应用或增加依赖。托管部署版本没有读回，源码验证不能代替实际后台保存。

实际缺口：官方 YAML 序列化将日期保留为字符串，带引号日期使博客 `z.date()` 报错。`src/lib/article-date.ts` 只补同一字段的严格 `yyyy-MM-dd` 日历日期转换，同时保留原生 Date 和虚拟页缺省日期。测试草稿使用真实序列化格式，内容集合通过后继续交给原生博客 Date 规则。
