## 工程接入

1. `motion-ranges.ts` / `works-motion.ts` / `home-motion.ts` 增加 prepare、expand、wall 共享进度，沿原四卡区间接续；重载/hash/返回直接初始化当前进度。墙实际覆盖四角后才推进 wall，反向先回收墙，再收回窗口。
2. `WallPortal.ts` 使用同一 Three renderer、同一 `RisingWall` 实例、一个有界半浮点 render target；不新增 Canvas、RAF 或依赖。窗口与全屏都取该场景，结束停止合成，卸载释放 GPU 资源。
3. `GlassRenderLayer.tsx` 维护 world/glass/glow → wall portal → 前景卡的顺序，进入 prepare 后撤前景卡；原几何与玻璃材质保持。实体墙和采样墙读取同一位置函数。
4. `GlassTriangle.tsx` / `GlassEdgeLight.tsx` 接入轮廓转动、展开与柔光回收；`RisingWall.tsx` 扩充实例覆盖竖屏，砖块尺寸保持。统一视觉参数见设计 SYSTEM 9.2.5，不在本文件另设数值。
5. `home.css` / `index.astro` 接入展开 spacer 和活动/静态路径的导航对比。opticsDebug 才启用只读 raw/rendered/coverage DOM 采样，普通入口不增加产品控件。

## 已修正及边界

初样两个三角面选择了错误共边，出现V形空洞；已沿p0-p2重新三角化。快滚时独立追随器可能先升墙，改为实际覆盖门禁并在反向回收时持有展开。极小wall尾数让整墙残留窗口外，显隐与回收阈值已对齐。8bit离屏目标截断白砖亮部、丢失砖缝，当前半浮点目标与主场景采用相同tone mapping。原有导航color过渡和quiet清理会令白墙上短暂失读，当前采用背板逐像素对比路径。

一次尚有滚轮输入时立刻点击墙导航的确认等待超时：实际停在滚轮目标y=7012，随后停定点击正常到y=7660。推断是后到的滚轮输入中断程序导航；原始结果保留，不称该次等待通过。

390px为模拟窄屏，非实体手机。实际系统减少动画偏好为false；已通过暂停控制实测两者共用的quiet内容分支，尚未独立切换系统偏好。无HDR扩展设备回退8bit，尚未在这类设备核对砖缝；本轮无FPS/实体GPU指标、BFCache或context-loss专项回归。留言仍显示真实未配置状态。
