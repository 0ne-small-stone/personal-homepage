# T13.11 关联控件键盘补验

对应 P17、R13/R09/R10、U13/U09；沿用 codex/t13-11-related-picker 和[草稿 PR #30](https://github.com/0ne-small-stone/personal-homepage/pull/30)。本片只补齐已实现关联控件的键盘验证和操作提示，不扩大文章、资料或笔记的编辑范围。

## 变更与验收范围

文章集合和固定验证稿的关联说明增加已实测的原生按键：↓/↑ 移动候选、Enter 选择、Esc 关闭；搜索框为空时 ← 聚焦最后一个已选项、Backspace 移除。两处仍共用41个选项和同一原生 select，正文、候选、解析器、前台路由、依赖和设计资源均未改。

上一轮旧表单（标签12）仍保留“重复”搜索词和未知未保存输入；只读观察并继续保留，未刷新、保存或丢弃。独立打开固定验证稿（标签15），初始 Save 禁用、原单条文章关联、草稿开启，Source 正文与摘要保存为本机只读基线。

## 逐步实测结果

1. Source 模式展开候选后 Esc：列表关闭，焦点留在 combobox，正文/摘要相同，Save 仍禁用。
2. Source 模式搜索 PDF，↓ 展开第一条笔记，再 ↓ 移至资料，Enter 选择 PDF 阅读功能样本：原文章保留、资料 chip 新增，正文/摘要相同；Save 仅因关联变更启用。
3. 清空搜索词，← 聚焦该资料 chip、Backspace 移除：回到原单条文章关联，Save 恢复禁用，正文/摘要相同。
4. Editor 正文先获得焦点，再点击关联框、Esc：列表关闭，焦点留在关联框，Save 禁用。富文本 HTML 比对曾显示不同，差异实际仅为点击图片后临时的 ProseMirror-selectednode class；切 Source 比对 Markdown 完全一致，不能把 DOM 选中样式判为正文变更。
5. Editor 搜索 PDF，↓、↓、↑ 返回笔记候选，Enter 选择算法笔记；切 Source 后正文/摘要相同。← 和 Backspace 移除测试笔记，最终原单条关联、Save 禁用。

本片没有点击 Save，测试值均通过原生控件恢复，远程内容保持上一轮恢复结果。干净表单未复现未知输入，原因仍未确定；不把旧异常记录改成“已修复”，也不覆盖旧表单。

## 工程检查与交付

官方固定 ConfigSchema、YAML 序列化通过；46个知识条目、41个已发布候选、两处原生 select 保持一致，48个内容文件与基线相同。npm run check：27文件，0 errors/warnings/hints。仅说明文案改变，实际构建由本片 CI 核对，不重复前台关联构建和 PDF 验收。

托管新增提示实际显示、最终提交及 CI 结果交付前补录。截图和含账号信息的 UI 基线仅留本机；仓库机器证据另存，无凭证或未知未保存正文。

## 用户复验

[打开固定验证稿](https://app.pagescms.org/0ne-small-stone/personal-homepage/codex%2Ft13-11-related-picker/file/article-draft)，在“关联内容”输入 PDF，按 ↓/↑ 移动并 Enter 选择；Esc 关闭。清空搜索词后 ← 聚焦测试选择，Backspace 移除。选择变更需 Save 才写入工作分支，正式网站仍需合并/构建/部署。
