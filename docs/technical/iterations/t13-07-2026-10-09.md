# T13.07 图片选择取消与正文保留

P17 / R13 / U13 / T13.07。基线 T13.06 `d922e0ec02b3f420f541638bdaf3e963aca31d4c`，分支 `codex/t13-07-media-cancel`。原生选图弹窗关闭与输入保留实测通过，用户体验待反馈；关闭后焦点没有自动回到正文，系统文件选择器取消未验。

## 范围与最小改动

仅使用 `editor-draft-check.md` 及已有 T13.02 图片，沿用成熟 Pages CMS，不改首页、应用源码、依赖、账号或私人原始资料。现成 MediaDialog 提供 Close/Escape 与选择清空，直接复用；其关闭行为不等于中止上传。[来源及能力边界](../REFERENCES.md#t1307-图片选择取消来源2026-10-09)记录，不新建上传器或托管后台。

`.pages.yml` 两处 body description 补原生入口：Editor 空行输入 `/` → Image；Close/Esc 取消、关闭后点击正文继续；取消不会撤回已上传图片，Upload 选中文件立即写入公开仓库，正文另点 Save。保留 alt/图下说明及固定稿的小于 1 MiB 建议与构建/部署边界。现有 `site.yml` 加本轮 `codex/t13-07-*` push 范围，部署条件不变。设计资源新增 0。

## 真实后台结果

先在表单修改测试标题及 Source 正文，明确加入未保存标记；确认准确输入后进入 Editor。用原生 `/` → Image 打开 Select images。没有点击正文 Save、没有提交新文件，也没有点击图片 Select。

| 操作 | 实际结果 |
| --- | --- |
| 未选图片，点 Close | 弹窗关闭，测试标题保留；关闭前后编辑器 HTML 相同，已有图片保留 |
| 选中已有上传样本，不点 Select，按 Esc | 关闭动画结束后弹窗消失；标题/编辑器 HTML 不变，正文仍只有原来一张图片，没有新增图片 |
| 再次打开选图 | Select disabled，前次选择已清空 |
| 打开工具控制的 Upload 文件选择，不提交文件，再 Close 选图弹窗 | 正文/标题仍保留，无图片上传。工具没有文件选择取消方法，空文件列表被拒绝；这项不是系统文件选择器 Cancel 的验收 |
| 关闭后继续编辑 | Close/Esc 后 document.activeElement 是 BODY，焦点未自动回正文；重新点击正文可继续输入，切 Source 后两段测试标记与原图 Markdown/alt 仍在，Save 可用 |
| 放弃临时输入并重载 | 标题/Source 正文与进入时相同，Save disabled，临时标记不在原稿 |
| 提示推送后打开固定稿/集合新建 | 两处正文说明实际可见；沿用原生 Editor/Source、Upload/Select/Close，不新增控件 |

取消前后远程 head 同为 `1836f5d5871226f6c834cb49ede50ba26eecc437`，没有正文或媒体提交。提示接入后 src 树 `ce517c995c9205204ccfeebc31492bea124589bf` 与基线相同，全部 48 内容文件和图片所在源树均未变化。实际浏览器取消结果与 GitHub 读回相互核对，不能只用缓存源码推断已通过。

## 体验与剩余问题

[打开验证稿](https://app.pagescms.org/0ne-small-stone/personal-homepage/codex%2Ft13-07-media-cancel/file/article-draft)，Editor 中在正文末尾另起空行输入 `/` → Image，选中已有样本后不点 Select，Close 或 Esc；点击正文继续，核对原图和测试文字都在。需要放弃测试输入时不 Save 再重载，原稿恢复。不要上传新文件来验证取消。

系统文件选择器 Cancel、已经开始上传的中止/回滚、上传失败、手机与屏幕阅读器仍待验；关闭后自动恢复编辑焦点未通过，正文说明只是可操作的继续路径。不存在“取消后上传文件自动删除”的承诺。T13/U13 整体、离开确认和 T16 正式部署未完成。下一片可单独验证上传失败时的错误反馈与原正文保留。没有合并或部署。
