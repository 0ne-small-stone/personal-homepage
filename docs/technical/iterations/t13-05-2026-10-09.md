P17 / R13 / U13 / T13.05。基线 T13.04 `629e4cab14a6e647586c1304d72e98d755edcda5`，分支 `codex/t13-05-unsaved-exit`。本轮只处理未保存输入的保留/放弃说明与真实取消结果，不推进下一功能或首页代码。提示已接入，二次离开确认仍未实现；用户体验待反馈。

## 实测发现与最小改动

原先预计检查原生留在编辑/继续离开提示，真实界面发现：已有稿修改标题和 Source 正文后，点击侧栏“文章”直接回列表；新建有效测试字段后点面包屑也直接返回，没有观察到确认。再次打开旧稿为原文，再次新建为空。因此取消/放弃可用，但防止误离开并没有通过。

当前官方配置没有找到导航拦截开关，依据见[来源记录](../REFERENCES.md#t1305-未保存说明与原生边界2026-10-09)。本轮在 `.pages.yml` 两处文章 title 增加原生 description：“需要保留修改时先点击 Save，再离开。返回列表会放弃未保存内容。”不把这句说明当确认弹窗、自动保存或恢复保障；不注入托管页面脚本，不自托管或替换 CMS。UI 仍由成熟托管后台负责，新增资源/依赖/应用代码为 0。

`site.yml` 补充 `codex/t13-05-*` 的既有 push 检查范围，保持后台用户保存后的检查约定。沿用三项检查与默认分支部署条件，主分支保护没有修改。

## 真实托管结果

使用已有登录，在本轮工作分支测试；没有点击 Save，没有提交测试正文。

| 操作 | 实际结果 |
| --- | --- |
| 打开已有稿 | 原标题、摘要及 Source 正文可读；初始 Save disabled |
| 改标题与正文，再点侧栏“文章” | Save 变可用；直接返回四篇列表，没有离开提示；重新打开标题及 Source 正文与编辑前一致 |
| 改标题，执行 CUA reload | 未观察到确认，刷新完成后标题恢复原文、Save disabled；只代表该工具操作，不代表所有浏览器手势 |
| 新建填标题/摘要/地址/Source 正文，不 Save，点面包屑“文章” | 返回四篇列表，没有新稿；再开新建标题/地址为空 |
| 提示配置推送后刷新新建 | 标题旁说明可见，原生 `aria-describedby` 指向说明节点 |
| 重新打开已有文章、固定验证稿 | 两处均显示同一说明，标题保持实际已存值；已有文章 Save disabled |

原生文章更多菜单在本次编辑页只观察到 View on GitHub，没有可见的取消修改项；本轮放弃通过原生“文章”返回完成。没有测试媒体上传取消、网络失败、手机、浏览器关闭和正常键盘刷新，也没有称普通字段 `readonly` 或离开说明可以控制仓库权限。
