## 实际浏览器范围

桌面1280×720、390×844和320×740是桌面浏览器视口，不能替代真手机。个人介绍首访0个React island/0 canvas/1个暂停的原生audio；音乐页才加载曲库，实际选曲后出现悬窗。首页、知识和音乐间原生导航使用同一audio session，显式暂停、原生进度归零与继续正常。

无操作播放68.166秒：localCatalog 12→12、neteaseCatalog 26→26、progress 135→391。这里的计数为显式loopback performanceDebug观测，不在公共线上启用。

首页可见停驻：桌面51.534秒scene96/render915保持；窄屏116.181秒scene1295/render11806保持。首次原生PageDown唤醒。运动与停驻分记，rawDelta单个样本不能作为平均FPS。使用Drei有限降DPR后，窄屏绘制缓冲281×633、CSS375×844，构图与DOM控件定向查看；没有真机GPU或CWV结论。

原生音乐菜单、Escape回到打开按钮、320黑胶歌词、静态歌词打开/关闭/重入均实际检查；同一歌词只有一次浏览器GET，其余两次来自HTTP验收。最终320首页留言按需打开，真实Giscus显示1评论/0回复，未登录；没有执行OAuth、发表或回复。

最终320的Someone中英切换、知识搜索“PDF 阅读验证”3条结果、搜索进入四页PDF及原生页码输入、返回后关键词/结果恢复也已检查。页码输入后的早截图不能单独证明目标页画布已完成滚动，不扩写为整套PDF翻页/缩放验收。
