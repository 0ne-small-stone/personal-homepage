## 实现与复用范围

`.pages.yml` 新增原生 `articles` collection，读取已有 `src/content/docs/knowledge/blog` 平级 Markdown；列表含标题、草稿和日期，按日期降序，支持标题/摘要搜索。新建使用现有字段、Markdown 编辑器与媒体配置，默认 `draft: true`、`kind: article`、`example: false`。空主题/标签不输出，应用 schema 沿用原生默认数组。固定文章验证入口和未建模字段 merge 保留。

新文件模板 `{fields.entryId}.md`；地址标识必填且校验小写英文/数字/单个短横线，关闭 rename/delete/subfolders。已有语义 ID 不适用于原生 UUID 校验，因此沿用当前格式，不迁移原文。地址标识仍是可编辑字段；保存后保持不变由文案与内容检查承接，关闭重命名不能作为 ID 只读保证，也未验证重复 ID 输入的托管提示。

`site.yml` 仅增加 `codex/t13-04-*` push 检查范围，复用三项检查及原部署条件。没有新依赖、服务、内容集合、主题或设计素材。官方来源与版本边界见[技术参考](../REFERENCES.md#t1304-原生文章集合来源2026-10-09)。
