## 改动与复用

一份栏目配置、一份 PublicDirectory，分别接入主站 SiteLayout 和 Starlight SiteTitle 组合层。六个入口依次是学习、展示、常用网站、音乐电台、关于我、留言墙。均为真实普通链接，sitePath 生成部署前缀；当前位置精确等于栏目首页时标 page，属于栏目子页时标 location，首页和 404 不标记。修复 Starlight 三处手写 sidebar 链接的重复 base，框架负责其规范前缀。

原生 details/summary 覆盖展开、收起、键盘与无脚本访问，不新增控件库。少量 custom element 补关闭按钮、Esc、外部点击、焦点离开和历史恢复，连接/断开时注册/销毁事件。关闭按钮和 Esc 恢复触发焦点，焦点离开和外部点击保留实际目标。只对 SiteTitle wrapper 解除局部裁切；原生搜索、主题切换、学习侧栏、正文目录、PDF 阅读均保留。全站目录不参与 Pagefind 正文索引。

所有知识正文与内容字段未修改，44 个既有内容文件保留，正式文章仍为 0。原始资料完整保留，本机 PDF 副本在忽略目录。最新设计工作区已有首页滚动章节和品牌资产，本轮没有合并共享工作区的未提交设计文件，工程页头仍使用过渡基线；该边界不改变六个功能栏目去向。

## 用户体验与复现

1. 打开[文章](http://127.0.0.1:4322/personal-homepage/knowledge/blog/article-reading-check/)，站名旁点“全站目录”。学习显示“当前栏目”，可以打开其余五个栏目；到关于我页面再次展开，应标“当前页”。
2. 打开[首页](http://127.0.0.1:4322/personal-homepage/)，右上角使用同一目录进入学习。目录外点击可收起；“关闭目录”与 Esc 收起后焦点回到触发控件。Tab/Enter/Space 也可操作。
3. 在文章页试原生搜索、正文目录和手机学习菜单；在[概率资料 PDF](http://127.0.0.1:4322/personal-homepage/knowledge/resources/probability/probability-lecture-0/)打开全站目录，PDF 仍可阅读。
4. 刷新、前进后退、手机宽度和明暗主题逐一核对。旧 4363/4364 是上一轮冻结快照，不承载新目录；本轮验证使用 4322。

在本切片根目录运行：

```powershell
npm run check
npm run build
node tools/verification/public-directory-check.mjs
node tools/ci/dist.mjs --local-preview
npm run preview -- --background --host 127.0.0.1 --port 4322
```

需要 PDF 时先按 README 准备本机副本；没有副本则显示真实待配置状态。正式发布使用不含本机副本的构建与默认 dist 检查。目录脚本检查是仓库内可重跑的产物验证；自动化 Edge 的实际输出和已查看截图保存在本轮证据，不要求给项目新增 Playwright 依赖。
