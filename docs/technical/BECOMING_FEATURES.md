## 访客功能

| 功能 | 当前行为 | 入口与边界 |
| --- | --- | --- |
| 学习总览 | 资料、文章、笔记统一列表；类型与主题组合筛选、标题升/降序、结果数量、清空及空结果；URL 可分享 | [Becoming](https://0ne-small-stone.github.io/personal-homepage/knowledge/)，当前 35 份资料、5 篇笔记、1 篇文章功能样稿 |
| 导航和外观 | 黑灰 Framer 风格、shadcn 灰色选中侧栏；桌面侧栏、手机菜单；原生浅色/深色/系统主题 | 总览、PDF、文章阅读、文章与标签列表共用外壳；其他栏目保持各自已发布版本 |
| 文章列表 | 按时间浏览；日期、标题、短摘要；每页 5 篇、原生分页 | [文章](https://0ne-small-stone.github.io/personal-homepage/knowledge/blog/)；只有 1 篇公开功能样稿，正式文章待添加，多页机制用隔离样本验过 |
| 可选标签 | 标签结果列表、匹配文章、返回原标签结果 | 站点后台开关；关闭后不生成标签页、不显示标签入口/搜索标签过滤，原始标签保留 |
| 文章/笔记正文 | Markdown 渲染、章节目录、代码/图片/链接、上一篇/下一篇等原生能力 | [文章样稿](https://0ne-small-stone.github.io/personal-homepage/knowledge/blog/article-reading-check/)；外部收藏笔记直接进入作者原站 |
| PDF 阅读 | 本站嵌入 PDF.js，页码跳转、缩放、文内搜索、页面/目录侧栏及收起、独立阅读器、下载、失败重试 | [公开四页样本](https://0ne-small-stone.github.io/personal-homepage/knowledge/resources/reading-guide/)；36 份课程 PDF 为本地附件，线上如实显示尚未接入 |
| 沉浸阅读 | 点击直接全屏，隐藏导航/工具及辅助信息，只保留正文/PDF；电脑 Esc、手机右滑退出 | 支持原生全屏的浏览器进入系统全屏；不支持的手机使用网页铺满。外站阅读由原站控制 |
| PDF 沉浸排布 | 进入自动选择舒适单/双页；1–4 固定每组页数，0/5–9 解除固定；Ctrl 加减号/滚轮缩放，F 适配完整页 | 模式与缩放独立；物理按键兼容中文输入法；页面无常驻快捷键说明 |
| 自动续读 | 文章恢复段落及段内位置；PDF 按文件恢复页码、页内横纵坐标及普通阅读状态；沉浸离开也保存 | 同一浏览器、同一站点本地保存；明确章节链接优先；清除站点数据会移除记录，不跨设备/域名同步；独立 PDF 阅读器沿用原生记忆 |
| 内容关联 | 显式关联条目、反向引用；只解析已发布有效 ID | 不生成知识图谱，不自动把任意正文链接变成关系 |
| 搜索与返回 | Pagefind 搜索站内已发布文本；类型、主题和可选文章标签过滤；阅读后返回原搜索/总览/文章/标签来源 | 返回保留筛选、排序、结果位置和焦点；站内搜索不索引 PDF 内文，PDF 内文搜索在阅读器内使用 |

## 内容维护与发布

- Pages CMS 支持文章和自写笔记正文/插图、资料及收藏笔记元数据、关联条目与博客标签开关。草稿不会进入生产页面、搜索或关联结果；公开仓库里的草稿文件本身仍可被读取。
- 内容分支保存后生成关联候选，原有短效令牌任务在验证后自动回写候选并检查新提交；main 和 PR 不回写。编辑内容通过受保护 PR 合并后才发布，CMS 的 Save 不等于已上线。
- GitHub Pages 由 main 的成功流水线发布；保留 Repository checks、Workflow syntax、Astro build 三项保护。发布不携带本地课程原件、音频、登录数据或临时分页样本。
