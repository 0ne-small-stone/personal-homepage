## 逐项验证

1. 在冻结快照选择“笔记 + 阅读与整理”，应仅出现自写笔记功能样稿；打开即读正文、目录、代码和已有插图。返回保持主题/类型/排序和条目焦点。
2. 搜索“验证”，展开“类型”，选择笔记，再选主题“阅读与整理”，应为1条。进入笔记再“返回搜索结果”，词、两个筛选和结果焦点保持。类型资料/文章及可选标签用同一原生搜索面板。
3. 从笔记正文或关联区进入四页PDF功能样本，直接出现阅读器；原生键入第3页并确认，展开“管理页面”再“收起PDF侧栏”，应保持第3页。资料和文章的反向来源应有此功能笔记。
4. 后台“我的笔记 → Add an entry”，标题/摘要/地址标识/正文必填，默认草稿。编辑后Save并重新打开核对；在原生图库选图会使用笔记对应的正确相对路径。
5. 当前学习区搜索“验证”并选笔记，应无结果；功能笔记不在列表、目录、生产正文与反向来源。已存的验证正文保留为草稿，原48内容未改。
6. 标签浏览默认开启；关闭后原始文章标签保持，标签入口/路由/搜索标签过滤停用，类型/主题和正文继续可用。该两态已通过隔离构建与实际界面核验。
