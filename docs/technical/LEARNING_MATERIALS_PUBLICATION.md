## 构建与本机验证

- 本机先运行“npm run materials:fetch -- --source <原始资料目录>”，只验证/复制本地原件，不联网、不上传；原件变化会拒绝。
- 获准上传且附件发布后，独立克隆运行“npm run materials:fetch”获取固定副本；“npm run build”会自动校验/准备同一批附件。
- CI在类型检查前准备附件；原生PDF公开检查覆盖所有公开条目，并拒绝未登记文件。旧public/local-materials仍不得进入正式产物。
- 通过现有PR三项必需检查后合并main，再观察Pages部署。公网至少验证用户当前物理实验23页文件和一份超过50MiB的大文件的加载/范围请求；明确区分本机完成与已上线。
